# Cloud Hosts 1.2.2 深化验收

本轮保留现有功能范围，重点处理大量输出和连接生命周期。

## 实修与补齐

- 输出历史改为分块缓存，避免每个小块到达时重新复制整段 256,000 单元历史。增量游标、缓存上限保持兼容；淘汰时保留完整 Unicode 边界，UI 对历史缺口作明确提示。
- 终端输入/读取/缩放直接校验会话所属主机，去除这些高频路径上的主机库磁盘读取。角色授权仍由 Core 检查。
- 输入等待驱动管道写入完成后返回，并传播写入错误；CLI socket 或插件 HTTP 客户端断开时取消等待中的读取，Shell 保留。
- 桌面只有准备完成才标记 ready；连接中标记 connecting。关闭会回收未完成 HTTP 握手的连接，避免关闭操作一直等待。
- 既有断开按钮在连接期间可取消；切换页面后仍能取消同一条待建立连接。重复连接复用仍然有效。
- 多个终端间切换后，重新进入页面恢复最后选中的会话。

## 有边界的性能测量

`test/terminal-output-test.mjs` 对同等追加/增量读取操作进行了五次对照，以下为中位数。每组约 32 Mi 个 UTF-16 单元；这是输出缓存模块的 CPU 耗时，不是整个应用、网络或远程桌面的加速倍数。

| 缓存工作负载 | 原实现 | 分块实现 |
| --- | ---: | ---: |
| ASCII | 229 ms | 2 ms |
| 中文 / Emoji 混合 | 455 ms | 3 ms |

真实本地 PTY 测试：154,000 字节中文/Emoji 粘贴的 SHA-256 与原始输入一致；超过 516 万文本单元输出后，缓存仍不超过 256,000 单元，尾部无 Unicode 替换字符，后续命令仍可交互。该次高输出量测试约 191 ms，属于本地 fixture 单次观测。

已安装版本的轻负载测试：首屏 JS 16,150 bytes；8 次回传中位数 2 ms，最大 3 ms；3.2 秒空闲观察期无额外读取请求。未把缓存优化换算成真实远程桌面帧率。

原始记录：`artifacts/cloud-output-performance.json`、`artifacts/cloud-performance-after.json`。

# Cloud Hosts 1.2.1 性能与体验打磨

本轮只优化现有功能，没有增加产品功能入口。

## 对照测量

同一台 macOS / Apple Silicon 电脑，隔离主机库、实际 PTY 和本地 SSH 协议 fixture。窗口保持隐藏，用前台 document 调度测量轮询影响。最终结果来自安装到 `/Applications/Agents Company.app` 的构建。

| 指标 | 1.2.0 基线 | 1.2.1 已安装版本 |
| --- | ---: | ---: |
| 概览首屏 JS | 559,413 bytes | 16,147 bytes |
| 首屏准备时间（单次） | 170 ms | 73 ms |
| 输出回传中位数（8 次） | 44 ms | 2 ms |
| 输出回传最大值（8 次） | 61 ms | 3 ms |
| 3.2 秒空闲期的读取请求 | 13 次 | 0 次 |

首屏 JS 减少约 97.1%。回传时间从发送 Shell 输入到 UI 收到包含结果的响应，不包括浏览器绘制完成或真实云端网络延迟；单次首屏观测不是统计性能承诺。空闲终端通过最多 15 秒的等待请求续接，并非永久零请求。

原始数据：仓库 `artifacts/cloud-performance-before.json`、`artifacts/cloud-performance-after.json`。复现：`npm run test:cloud-performance`。SSH/桌面传输 fixture 不代表真实远程桌面的帧率。

## 具体调整

- 概览、终端、桌面控制和 VNC 分开加载；RDP 不加载 VNC 解码代码，终端样式加载完成后再挂载。
- 复用现有 terminal-read API，增加可选 waitMs。Core 在输出到达或 Shell 退出时唤醒读取者，返回前再次授权；旧客户端默认不等待。
- 输入按短时间片合并并保持顺序；尺寸变化合并；每个终端持有独立读取游标，切换后取消旧读取，防止旧结果污染新会话。
- 无变化的主机列表不重绘；重复选择当前主机或页签不销毁工作台；隐藏页面暂停列表和桌面状态轮询。
- VNC 连接事件驱动画面状态；防止重复监控循环和旧连接回调覆盖新页面；只读同时禁用 Ctrl+Alt+Del。
- 统一字号、间距、描边与低饱和配色；工作区随窗口伸缩；消息浮层不挤动终端；缩小常驻说明，主机 ID 保留在折叠详情中。
- 表单自动聚焦，保存中避免重复提交或导航丢失；显示密码时仅请求密码，并在页面隐藏时收起。
