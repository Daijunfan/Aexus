# MarginNote 4 本地学习验收范围

目标：macOS MarginNote 4 的本地阅读、摘录、笔记整理和复习工作流。版本：0.7.0。OCR、手写识别、联网 AI、同步、导出和备份扩展不在本次要求内。

依据：[MarginNote 4 官方手册](https://manual.marginnote.com.cn/mn4/en/)、本机原版文库界面及本插件实际 CLI/隐藏窗口测试。下表明确可操作内容，不把“存在按钮”当作通过，也不承诺商业软件的私有实现、全部参数或每个像素相同。

| 工作流 | 已落实的可操作内容 | 数据与验证 |
| --- | --- | --- |
| 文库与基础阅读 | 原有格式解析、文件树/网格/列表、批量操作、回收站、连续/分页、手势、缩放、目录、搜索与书签 | 原有安全/读取/UI 回归；1061 页 PDF 学习流程 |
| 多文档阅读 | 文档标签、关闭标签、同文档不同位置或不同文档并排对照 | 第二阅读位置独立保存；重开恢复 |
| 页面工作 | 指定页缩略图、折叠/展开、旋转、裁剪、重排、跨文档组合、插入空白页 | 生成新的真实 PDF；原件 SHA-256 保持；新文件继续使用原阅读/摘录 API |
| 笔记本与留白 | 空白/横线/方格 PDF；文字留白卡片绑定原文；页边、页后展开、折叠标记 | 保留原文 locator/hash；原文改变后不错误套用定位 |
| 手写 | 图层新建、选择、显隐、锁定、改名、合并与撤销；压感数据；套索移动/改色/换层 | 压感数据经 Core 验证并渲染；实测鼠标输入，未声称测试过未连接的压感硬件 |
| 脑图批注 | 空白画布自由笔迹、卡片绑定笔迹、整笔擦除 | 画布按世界坐标保存；卡片笔迹随节点移动；共享图层与撤销 |
| 摘录 | 文字、矩形、任意多边形套索、彩色原文标注和 durable PNG | 原 PDF 实际裁切；不以浏览器截图代替共享 Core |
| 脑图整理 | Shift 多选、摘要节点、复合卡片、向右/向下/放射布局、子树聚焦 | 合并保留原卡片作为可展开子卡片；来源与原始图片不丢失 |
| 关联 | 单向/双向跨分支关联、跨学习集引用、标题命中关联 | 保留稳定 ID；来源跳转展开对应子脑图；删除目标不伪装成功 |
| 内容表达 | Markdown 与 KaTeX 公式阅读、复合卡片内原文/图片阅读 | Core 输出消毒 HTML；本地字体资源，无外部脚本 |
| 复习 | 牌组创建/命名/归档/恢复、正反面、文字挖空、图像遮挡、四档评分与撤销 | FSRS 计划与日志原子保存，普通图片翻面前隐藏 |
| 学习统计与个性化 | 每日复习次数、观察回忆率、目标保持率、最长间隔、离线参数训练 | 真实本地优化器；不足 50 次跨日观察时明确拒绝训练 |
| 状态安全 | 全部新增持久功能由 CLI/Core 实现；版本检查、恢复性删除、撤销/重做 | GUI 与宿主 CLI 共用 93 个声明命令；不在浏览器存储业务数据 |

实现语义：三种脑图布局具有明确的稳定位置算法；页面重组产生新文档而不是改写原件；留白的展开区放在对应页后，不重新流式排版 PDF 字里行间。原版学习编辑界面的逐像素对照受本机原版许可限制，因此功能验收与原版像素/硬件一致性是两个不同结论。

复现：`npm test`、`npm run build:plugin`、`npm run test:ui`、`npm run test:workbench`、`npm run test:advanced`、`npm run test:host`、`npm run test:study`。原生验收：`WORKBENCH_NATIVE=1 node tests/advanced-ui.cjs`。测试使用隔离目录、隐藏窗口，模型调用为零。
