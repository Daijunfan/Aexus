## 视觉原则

以 Telegram 的多配色、昼夜搭配、柔和渐变、圆角控件、明确反馈作为参考，建立阅读器自己的视觉系统。文档、笔记与脑图继续使用各自的布局，不把阅读工作流改成聊天流程。

色彩承担识别与层次：全局配色控制界面强调色；文件类型、学习集图标、卡片标签提供辅助辨识。原始图片、摘录颜色和笔迹颜色保持独立。阅读纸面不铺装饰纹理。

动效应短暂且由操作触发。优先使用颜色、透明度和不影响文档坐标的反馈；不得让页面、卡片世界坐标或手写层因装饰动画漂移。减少动态和页面后台状态必须受尊重。禁止用持续动画掩盖等待、卡顿或未保存状态。

## 本轮落地

新增外观工作室：8 套配色（晴空蓝、薄荷绿、鸢尾紫、蔷薇粉、日光金、珊瑚橙、暮光靛、石墨灰），每套配合明亮、深夜与暖纸模式。提供纯净、柔光、星点、涟漪 4 种工作区背景，示例实时预览、明确应用与恢复默认。

设置通过 `settings.get/set` 的 `uiPalette`、`uiBackdrop`、`uiMotion` 持久化到当前文库。取消预览不保存；应用只写变更字段，不覆盖其它客户端调整的字号或导航。系统“减少动态”优先于显式完整动效选项。旧文库只读获得默认值，不在读取时改写状态。

侧栏新增按稳定学习集 ID 分配的彩色标识、文档数与卡片数徽标；文件卡片、文档引用、分段切换、菜单、对话框、复习卡片统一圆角、层次和焦点样式。收拢工具区减少半行控件露出；完整工具仍可展开或滚动访问。新样式集中在 `ui/visual-polish.css`，主题值在 `ui/visual-theme.mjs`。

本轮继续补齐标题词条分组：看板可按分号别名分组、二级分组、精确词条过滤，保存后可生成引用脑图并撤销。跨集结果保留 owner 身份；同一卡片多别名属于多个组，选择和总数仍按唯一卡片计算。关闭标题链接后，该分组在当前学习集不可用。词条预览新增“检索相关卡片”，进入全库文本搜索且不自动离开原文。

## 后续精修顺序

首先完成更多直接操作：工具按场景组织、减少嵌套对话框、稳定的弹出卡片与可调整选区。每次调整需重新验证鼠标、键盘、取消、冲突和撤销。

继续扩展视觉表达：自定义主题编辑、主题导入导出、更多原创背景与图标、精准的页面切换和状态反馈。优先做有用途的元素，不用大范围循环动画占用阅读注意力。

原版包迁移、独立同库原生多窗口、系统级深链、Obsidian 双向联动仍有缺口。备份断点续传已在后续独立任务 API 中实现，复制与整文件校验的恢复边界见增量说明；物理断电和外置盘行为仍单独验收。界面主题不能代替其它功能的实际验收。

设备与规模验收继续保留：实体笔和掌拒、Windows/Linux、真实断电与外置盘拔插、长时间图片/笔迹混合数据。不得从无头浏览器或小型样本推断全部设备体验。

## 本轮精修中发现并处理的问题

标题词条看板最初可以保存，却被学习包的旧分组校验拒绝导入。现已补齐包校验，并验证原卡片、生成引用、撤销和可移植包往返。

外部调用关闭标题链接后，打开看板曾继续使用过期的学习集缓存，使分组选项短暂可用。现在打开看板读取最新学习集，并核对用户未切换范围；Core 仍独立拒绝不允许的操作。

完整回归还发现文件列表被无关刷新重复重建，可能让拖动目标或键盘焦点丢失。相同文件数据现在复用原有文件卡片、树行与缩略图节点；文件版本、路径、列表布局发生变化时仍更新。新增测试同时验证“保持节点”和“实际变化仍更新”，原有真实鼠标拖动测试保留。

中间失败日志保留在本轮 artifacts 目录。最终验收必须由同一份运行时代码重新跑完整套件，不能把多个中间版本的通过结果拼成一份通过结论。
