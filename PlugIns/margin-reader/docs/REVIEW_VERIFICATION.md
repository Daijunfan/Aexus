## 当前行为

- 交互尺子支持各场景独立位置、鼠标与两点触控旋转、遮挡和沿尺边书写；尺线由 Core 与预览共享的几何算法生成，折叠源区域保留分段和笔压。
- 浮动工具栏提供三个基础笔型、独立命名笔刷、复制/归档恢复和 3–12 支笔管理；文档、脑图、卡片绘画和复习使用对应粗细控制，停靠/浮动位置可通过公开 CLI 保存。
- 文档、画布、卡片/复习分别记住笔宽；CLI 可省略 width 使用对应场景值。修改文档粗细保留卡片当前粗细，旧共享笔刷与模板可恢复原有粗细。
- 消失模式使用当前笔型、颜色和透明度，允许连续多笔，停笔一秒后开始淡出。临时笔迹不进入保存队列；切回旧普通笔刷默认退出消失模式。
- 开启完美图形后，密集往返涂抹停笔半秒即整笔删除；支持 PDF、脑图和嵌入笔记，抬笔不重复提交，冲突保留草稿，撤销恢复原笔迹。同步修复 PDF 页面刷新后的坐标偏移与跨卡片删除的所属图层锁定遗漏。
- 新卡默认标题提问、完整卡片作答；背面使用同一卡片实时内容。旧自定义问答兼容，独立分组排程及被移除分组的记录保留。
- 正反面文字、图片、音频、手写批注；同题按组揭示、刷新恢复及评分撤销。文字/图片强调可用相同组名并一起揭示。
- 独立强调与荧光笔出题。自动规则默认开启，正文、评论、强调、荧光笔、图层或笔记本变化，与题目更新在同一 Core 事务提交。
- 问题改变时重新遮挡；标签等无关编辑保留揭示进度。暂停不被自动恢复；手工改题退出自动规则，显式关闭自动更新可冻结当前题目。
- 无可用标记或无法生成合法题目的卡片保留日志，但退出复习队列并说明原因；恢复标记或撤销后恢复。引用源变化会更新引用题目的版本，拒绝旧评分请求。读取接口不写入状态。
- 图片裁剪/旋转同步变换强调与遮罩。仍存在的分组沿用排程，被裁掉分组保留历史；直接替换图片移除旧图形标记，保留文字、批注、手写及复习记录。撤销/重做恢复图片与标记。
- 连续摘录保存每个片段的原页与合成图映射。追加、删除、重选、跨集复制及导入恢复后，标记仍对应原图区域；荧光笔匹配每个片段的文档、版本、笔记本和页。复制/移动笔记本同步更新映射。
- 复习视图收起无关脑图工具栏；批量提取保留手工定制问题。

## 图片手写绑定的后续验收

图片内笔迹可按 imageBound/imageBounds 绑定。裁剪、旋转和匹配区域变换会同步处理坐标和压力；尺寸或显示比例变化仅改变投影，不改写原图。明确的整卡笔迹保持整卡行为。已有笔迹可绑定/解绑，局部擦除、套索、复制及解绑回画布使用同一坐标关系。

普通预览、复习和本地导出在图片上绘制绑定笔迹，并按分面和图层过滤，避免额外重复绘制空白手写面板。导出透明笔迹不会在自身线段交点重复叠色。原 PNG 保持独立不可变，撤销和可移植包保留笔迹。

同时修复脑图图片高度被重复减去标题/页脚的问题；复习竖图按视口限高保持比例，切换长题目时回到开头。

## 涂抹删除与坐标稳定性的后续验收

依据：[官方手写工具的 Scribble Erase](https://manual.marginnote.com.cn/mn4/en/handwriting-write-freely-documents-mind-maps/)。开启完美图形后，密集往返涂抹并停笔至少 500ms，会删除碰到的整笔。删除立即在停笔时提交，抬笔不重复提交；快速涂抹或关闭识别时保留普通笔迹，消失笔不删除或保存。

三个 ink.add 接口继续由 Core 处理原始轨迹；CLI 必须明确传入 geometry.scribbleErase:true。geometry.scribbleScope 可选择原作用范围或整张脑图；公开 study.ink.erase 新增 map 范围。一次整图删除覆盖可见画布及卡片背面，复用已有笔记本和所属笔记图层守卫，并保留隐藏/锁定笔迹、折叠内容与正面专用笔迹。整次操作对应一个撤销步骤，保留恢复后的笔迹 ID。

实际 PDF 鼠标测试发现页面元素被阅读器刷新替换后，原手势会用失效元素计算坐标；现在每次采样查找当前页。普通卡片笔画可以延伸到卡片外，并使用已有 card-relative 坐标语义保存和导入恢复；图片内绑定仍按图片边界裁切。

## 场景笔宽与消失模式的后续验收

依据：[官方手写工具文档](https://manual.marginnote.com.cn/mn4/en/handwriting-write-freely-documents-mind-maps/)的 Changing Pen Thickness 与 Vanish Mode。持久设置通过已有 study.ink.settings 保存；width、cardWidth、canvasWidth 分别用于文档、卡片/复习和脑图画布。三个 ink.add 命令的 width 改为可选，明确指定时仍覆盖设置。旧记录读取不迁移，首次设置变更保留原卡片粗细；旧共享笔刷/模板应用时恢复两个场景的原值。

vanish 与笔型分离，可沿用当前笔型、颜色和透明度。连续抬笔再写不会被“未保存笔画”阻止，多笔在最后一次移动后 1000ms 开始淡出；按住笔尖等待消失后仍可继续书写，已消失轨迹不会重连。关闭、Escape 或取消可清理临时绘图层。临时笔迹不进入持久 API 队列，不触发涂抹删除；显式 CLI ink.add 保持持久写入的既有含义。原 laser 选项继续兼容。

复习正反面编辑器现在沿用卡片粗细、颜色、笔型、透明度、笔压和消失设置；保存普通笔迹时仍明确使用自由手写。CLI 自定义颜色不在现有颜色列表时，设置面板、PDF 颜色选择和复习编辑器会保留该颜色。

## 浮动工具栏和独立笔刷的后续验收

根据官方手写工具文档继续实现工具栏、常用颜色、笔宽和笔刷复制管理。新的 study.ink.toolbar.set 保存各场景的浮动/停靠位置、笔刷顺序和连续/分级粗细控制。study.tool.save 增加 apply 与 pin，可在一个版本及撤销步骤内保存、加入工具栏并激活笔刷。

三个基础笔刷由 Core 提供稳定、按学习集覆盖的默认值；读取和展开工具栏不初始化或修改学习集。用户自建工具继续保留在笔刷库，工具栏最多 12 支，至少保留钢笔、荧光笔、铅笔各一支。删除进入可恢复状态。笔刷设置与工具栏布局分开保存，切换笔刷不移动工具栏。

界面支持再次点击已选笔刷打开选项、11 个颜色快捷键和自定义色值、透明度、当前场景笔宽、连续/分级调整、复制与恢复。键盘调节后保留滑条焦点，弹窗可在复习对话框中使用并重新展开。拖动时预览吸附，小窗口会调整工具栏方向；点击把手和 Escape 取消不产生布局写入。

保存选项与拖动均保留原版本检查。选项冲突后只在明确重试时合并所改字段，保留另一处对其它字段的修改。复习草稿只接受本编辑器成功提交的设置版本推进，外部卡片修改仍使草稿保存失败。

同时修复了可移植包将基础笔刷 ID 错当成自建 ID 重编号的问题，覆盖导入、历史撤销和整库备份检查。CLI 导航在笔画、工具栏操作或编辑对话框结束后再更新当前视图；画布草稿和工具栏拖动还会检查原学习集身份，避免相同版本号的不同学习集串写。

## 交互尺子与沿边书写的后续验收

依据：[官方尺子说明](https://manual.marginnote.com.cn/mn4/en/handwriting-write-freely-documents-mind-maps/)。新增 study.ink.ruler.set，分别保存文档、脑图、卡片和复习区域的启用、中心位置、角度、长度和遮挡设置。移动尺子不改写已有笔迹，关闭或取消也不修改原件。

界面可拖动尺身、拖动旋转柄、使用两点触控旋转/平移，也可用方向键微调角度。沿尺边书写时显示屏幕像素读数。各绘制接口通过 geometry.ruler 接受投影到笔迹坐标中的尺边，Core 与界面共用投影代码；只有靠近、沿着有限尺边运行的自由手写轨迹才吸附，远处、横穿或远离尺端的输入保留原轨迹。已有显式形状预设与角度辅助线保持兼容。

折叠 PDF 的尺边分成可见源片段，段间不补画隐藏原文；一次绘制仍为一个事务及撤销步骤。压力按原采样保留或在片段边界插值，尺子状态、笔迹、历史和本地包可恢复。复习草稿中移动尺子只推进本编辑器已确认的设置版本，仍保留对外部编辑的保护。
