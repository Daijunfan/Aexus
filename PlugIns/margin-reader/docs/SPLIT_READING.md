# 文档与脑图并排阅读（0.9.1）

学习集中仍只有“文档”和“脑图”两类内容。点击旁边的“并排”可同时查看；“⇄”交换左右。点击“文档”或“脑图”恢复单独查看。

并排状态使用同一份文档渲染器和同一个无限脑图，不复制节点、笔记或原件。文档自己的翻页、搜索和滚动独立于脑图；脑图的双指平移、指针中心缩放、拖动与原文回源保留。切换文档或单击来源主题不会关闭另一个面板。

中间分隔线可拖动调整文档与脑图比例。左右方向键微调；Shift+方向键加大步幅；双击或Enter恢复各占一半；Escape取消正在进行的拖动。鼠标松开时保存一次，不在每个移动事件中写状态。范围沿用已有文档比例30%–70%。交换方向保留文档自身的比例。拖动过程中保留当前PDF节点，结束后按原阅读位置重新适配。

布局模式按学习集保存；左右顺序和比例沿用当前文库的公开设置，重开后恢复。不同窗口和员工操作使用同一API。窗口内的脑图相机独立，分栏变宽或变窄时保持缩放和视口中心对应的世界坐标。

没有可用文档时，并排区显示文档列表／添加入口，脑图仍可编辑。文件缺失不会删除摘录或图节点。窄窗口并排时隐藏文库侧栏，为两边内容留出空间；回到单独视图恢复原侧栏策略。

## 员工与CLI

先以 `study.open` 打开学习集，读取最新revision，再执行：

```json
{"method":"study.view.set","params":{"setId":"SET_ID","expectedRevision":1,"view":"split","documentId":"DOCUMENT_ID"}}
```

`documentId` 必须属于该学习集，不能跨工作区访问。省略时保留当前成员文档，否则选择首个可用文档；显式null显示文档选择区。

```json
{"method":"settings.set","params":{"studyOrder":"map-first","studyRatio":0.6}}
```

`document-first` 为文档在左，`map-first` 为脑图在左；`studyRatio` 始终指文档份额。`view:documents` 可携带documentId保留正在读的文档，`view:map` 返回单独脑图。修改后台学习集的view不会抢占当前学习集。

`tests/split-read-map-ui.cjs` 以及隐藏原生窗口的共享测试验证两种方向、实际翻页按钮、分隔线鼠标与键盘、取消、原文定位、PDF/HTML切换、双指／缩放事件、刷新恢复、CLI同步、窄屏与无文档情况。

最终通过情况以固定构建的报告为准。实体触控板、跨操作系统和长期大媒体压力不由自动化输入结果代替。
