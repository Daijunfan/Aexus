# XMind 本地脑图能力对照

检索日期：2026-10-02；代码范围：Margin Reader 思维导图模块。本表按具体操作验收，不以选项数量、截图相似或命令触达替代全部功能正确性。网络同步、AI生成、云协作、账户与商业付费服务不在此轮范围。

| 官方能力类别 | 本轮实现 | 未计为通过的部分 |
| --- | --- | --- |
| 思维导图、逻辑图、组织图、树图、时间轴、鱼骨、矩阵与混合结构 | 13种结构选项、主分支独立结构、左右方位、同级等宽、间距、自动平衡；矩阵网格和括号实际绘制 | 商业版本的每一种特殊结构、精确版式算法及全部布局样式尚未逐像素对比 |
| 中心／主／子／自由主题 | 使用原有卡片树的稳定身份，支持根主题、浮动位置、快速同级／子级创建、重排及可撤销复制／剪切 | 所有原版手势、操作系统快捷键组合尚未逐项复制 |
| 主题样式、主题方案、彩虹分支 | 12个自制主题，31种轮廓选项，字体、颜色、局部标题格式、渐变、投影、线型与编号；复制样式和快捷样式 | 不附带商业壁纸、贴纸、插画资源；自制资源不冒充其原版素材 |
| 联系、概要、外框、标注 | 可编辑范围、概要主题与子主题、独立标注，关系起止样式、文字与曲线控制点 | 专有无规则外框控制、每种关系曲率模型与所有自动避让策略尚未对齐 |
| 标签、标记、笔记、图片 | 保留原有标签／笔记／评论／附件；优先级、进度、状态、符号、旗标；图片与绑定手写按真实图像几何显示 | 完整商业图标／表情贴纸资源、所有富媒体主题布局、标题内数学公式排版尚未逐项验收 |
| 折叠、聚焦、导航、专注 | 折叠仍使用同一模型；聚焦、空间方向键、缩略导航、完整总览、专注工作区 | 超大重媒体导图长期驻留、多屏和实体笔设备没有因文本样本而获得通过结论 |
| 编辑动画与切换 | 位置和颜色过渡、演示切换；指针命中前结束几何动效；系统减少动态与单图关闭选项 | 不声称与商业客户端的私有动画曲线、逐元素时间线或每个场景效果相同 |
| 查找、替换、筛选、全部笔记 | 完整图查询、显式分页、标记与任务条件、只读替换预览、版本确认后提交和撤销 | 正则替换和商业版所有搜索语法未实现；当前查询明确为字面文本与结构化条件 |
| Markdown／快速输入 | 缩进文本和Markdown标题追加为可编辑层级 | 完整Markdown文档导入中的表格、富文本、数学、HTML等语义不在该大纲入口范围 |
| 演示 | 同一公开队列驱动主题上下文页面、笔记、原文跳转和动画；超大单页明确限量 | 并非商业 Pitch Mode 的完整自动编排、每种版式、主题模板和全部演示导出行为 |
| 图片／SVG／PDF导出 | 完整或当前分支；SVG矢量主题、关系、文字、标记及手写；PNG和图像型PDF；保留嵌入摘录 | PDF全矢量、PPTX、每种专业打印选项及外部应用排版一致性未计为通过 |
| 原生 `.xmind` 工作簿 | 公开JSON模型检查、独立导入、多画布导出；图像安全处理，兼容提示与明确拒绝 | 旧XML、加密、未知扩展无损迁移；尚未商业客户端逐版本验收 |
| 任务管理／甘特图 | 主题日期、负责人、优先级、进度、状态及对应查询 | 甘特时间刻度、依赖调度、资源分配与商业任务面板未在本轮实现 |
| Margin Reader 阅读联动 | 同一张主题卡直接回到PDF/HTML原文；原文取消标注、摘录图像、复习与既有权限继续保留 | XMind不提供相同阅读器语义，因此这项按本项目既有回源与员工验收测试独立核验 |

## 官方依据

- 样式：<https://xmind.com/user-guide/style-new>。用于核对节点形状、文字、线条、端点、颜色、标签、外框、自动平衡及快捷样式类别。
- 结构：<https://xmind.com/user-guide/structure-new>。用于核对混合结构、逻辑图、组织图、树图、时间轴、鱼骨、矩阵和Brace Map的操作定位。
- 联系与概要：<https://xmind.com/user-guide/relationship-new>，<https://xmind.com/user-guide/summary-new>。
- 演示：<https://xmind.com/user-guide/pitch-mode-new>。用于核对智能编排、分支视图、演示模式和外观能力；本轮与其完整行为仍有差距。
- 官方公开SDK：<https://github.com/xmindltd/xmind-sdk-js>。用于理解JSON工作簿、Topic／Sheet、笔记、标记、图片、概要及打包模型；依赖公开结构不等于所有商业版本无损兼容。

## 结论边界

本轮交付的是有共享Core、可编辑结构、视觉设计、工作流和验收支撑的思维导图工作台。只有最终固定构建门禁中的测试可记为通过。完整商业XMind“全部功能／全部元素／完美一致”的总目标仍有上述明确差距，不使用该表的已实现项掩盖未实现或未验证项。
