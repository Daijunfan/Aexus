# 对标范围与验收边界

对照对象：hugohe3/ppt-master 官方 README，检阅日期 2026-10-07。
参考：https://github.com/hugohe3/ppt-master
原生图表导出库文档：https://gitbrent.github.io/PptxGenJS/docs/api-charts.html

本Engine没有复制该项目源码；采用独立的结构化场景、原生PPTX生成和模板局部OOXML修改。下表说明可比较的功能与尚未实现范围，不宣称全面胜出或任意模型一次生成完美结果。

| 对比方向 | PPT-maker 当前实现 | 验收方法 |
| --- | --- | --- |
| 先论证再设计 | 可修改大纲，明确确认后并行正文/版式，再由独立员工审校 | workflow与真实原生协议测试 |
| 可编辑交付 | 原生文本、简单图形、图片、表格与数据图表，非整页图片 | 解包检查对象、关系、内嵌数据；Office渲染 |
| 母版/版式 | 新文稿有原生master/layout；模板保持原始部件 | 包内对象数量与未触及部件hash对照 |
| 模板填充 | 按实际对象ID改文字、数值和备注；原始主题/图片/复杂内容保留 | 未编辑字节相同，定点编辑只改变预期part |
| 局部修改 | UI选页并要求自然语言修改，其他页面强制不变 | 每个非目标页面deep-equality |
| 图表数据 | 支持柱、线、饼、环图；嵌入工作簿同步修改 | Chart缓存与XLSX单元格双向回读 |
| 在线编辑 | 独立三栏UI，手动文字/几何/表格/图表/备注、撤销重做、页序 | 真实浏览器和隐藏Electron操作 |
| 持久恢复 | Contract checkpoint，明确请求ID，版本冲突、取消与父版本快照 | 真实Core重启/幂等/越权/取消验证 |
| 素材输入 | 本轮只有PPTX/POTX及TXT/MD/CSV、用户手动图片 | 不宣称PDF/DOCX/网页自动素材整理 |
| 丰富自由设计 | 4套视觉主题、8种结构版式及手动对象编辑 | 没有自动生成插画、图片检索、任意SVG转原生图形能力 |
| Office深层效果 | 已有复杂对象在模板原件中保留 | 尚未提供新建转场、对象动画、OMML公式、旁白与视频导出 |
| 模板扩展 | 保真模式保留原页面和对象集合，支持重排 | 不提供模板增删页/对象及完整母版编辑 |

## 本轮强调的精度约束

1. 只有明确最终导出才产生交付文件，文件始终为一个PPTX；中间状态不伪装成成果。
2. 下载比较真实解码字节与SHA-256；模板输出按原包局部修改，并检查关系完整性。
3. 新文稿文字容量、文本框重叠和画布越界出现阻断错误时不能导出；小字/复杂模板预览等非确定性问题明确展示警告。
4. 修改已有图表数值同时更新图表缓存和内嵌数据表，避免表面显示与“编辑数据”不一致。
5. 大纲确认、按页修改、手动编辑、审校与导出均保留可恢复阶段；无关工作不能被本引擎取消。

6. 新建导出额外审计ContentType目标、关系ID、二维图表轴及内嵌工作簿的表格引用；发现生成包结构错误阻止交付。正规化只作用于Engine自建输出。

这些是本轮已实现的工程约束，不等于已通过与PPT-master的同题视觉盲测。实际审美、内容准确度和跨PowerPoint版本效果仍需要目标材料与真实模型评测；本轮模型使用确定性loopback响应，验证真实原生协议与完整产物链，不评价模型创作质量。

## 下一次可复用对比实验

用同一组资料分别测试商务汇报、学术答辩、工程方案和已有企业模板。分别统计完整性、数字来源、非目标页保持、原生对象可编辑率、渲染溢出、人工修订时间和推理成本。输出原始文件供人工复核，不能以测试数量、工作线程数或生成文字长度代替质量结论。
