# Deep Research 2.0.0 — 空白引擎外壳

已按要求移除原有研究流程、模型协作提示词、证据与报告处理、文档导入、历史研究工作台以及相应领域实现。本目录仅保留引擎清单、静态空白页面、样式和拒绝执行旧操作的 CLI。

在 Aexus Engine library 中，将 Deep Research 卡片**拖入中央启动舱**方可加载。点击卡片不能加载。加载后不创建 Agent，也不发起任何研究任务。

原有历史研究任务由 Infra 保留并管理：拖入本引擎 → **Infra → Plan → 历史研究任务**。可以停止任务或停止后删除任务。Infra 只中断拥有匹配原生消息回执的 Agent 执行，其他 Agent 工作不受影响；如果无法确认中断则禁止删除，保留检查点供重试。

删除任务会从正常列表移除记录，并将工作流目录原子归档到 Core 数据目录的 `workflow-deleted/`，便于故障恢复。不会自动删除原有员工身份、会话记录和工作区。历史原件不迁移、不重写，其他 Engine 继续独立运行。
