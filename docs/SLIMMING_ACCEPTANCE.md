## 已落地的改动

1. 命令定义统一：公开 API 保持 275 项；120 条常规 CLI 路由使用声明式输入表，专用流式、文件与确认逻辑保持显式处理。
2. 引擎与 Core 解耦：共享状态默认值、会话辅助函数和工作区初始化分离；静态运行依赖检查没有循环。类型引用和动态依赖不计入这项静态结论。
3. 投递与事件分流：群聊和频道复用投递状态转换；保留各自权限、历史、回执及重试策略。外观、位置和阅读变化不再触发无关的执行状态重查。
4. 消息读取优化：独立 Worker 维护可重建 SQLite 索引；搜索和图库复用索引，Core 在异步查询后复核权限及隐藏状态。不同会话的历史和已读状态保持独立。
5. 前端复用与修复：列表订阅、草稿发送身份与持久化检查共用；媒体卸载保留播放位置，退出登录后的迟到授权不会重新挂载。播放中的节点卸载后会停止播放并清除来源。
6. Worker 依赖收窄：获取运行路径不再加载大型协议/命令目录。当前 Worker 入口 13,126 字节，路径模块 863 字节。独立 Electron/ASAR 测试验证索引查询、关闭、持久化与重启，不等同于完整安装包验收。
