# Avalon 0.58.1

## 本版变化

- 应用显示名、窗口标题、登录界面、当前 CLI / Agent 文档和安装包名称统一为 Avalon。
- 新增 avalon 命令入口；agents 和 anexus 兼容入口继续调用同一 Core。
- macOS 安装器将旧 Anexus.app / Agents Company.app 迁移到 Avalon.app，并保留应用身份、员工、原生会话、工作区绑定和数据目录。
- 执行中的员工还没有引擎输出时，工作消息框显示当前提交的任务；引擎输出优先，空闲后的未读回复继续保留。
- 进度订阅断开时处理 readline 连接错误，避免 EPIPE 导致 Core 退出；先过滤其他会话事件，减少不相关订阅检查。
- 包含 0.58.0 文件库更新：目录树与大图标浏览、文档封面、真实人员/存储来源、过滤搜索及可恢复文件操作。
- README 换为 Company、Messages、Plan 三张真实运行截图，并说明实际执行环境。

## 验证

通过：TypeScript、生成文档、活动消息与协作生命周期回归、安装器旧应用迁移、macOS arm64 候选与安装后隐藏窗口测试、实际应用名称/窗口标题/Company 页眉、三个插件窗口、终端、签名和归档完整性。原有员工、引擎、Team、原生会话和工作区绑定保持一致。

截图来自独立场景中的真实模型和 SSH 工作区；普通回归使用临时数据与确定性协议 fixture。Windows/Linux 桌面包与 macOS x64 本轮未验证。当前本地安装包为候选构建，第三方再分发审核状态没有改变。

## 关联采集部署

外部新闻采集器是独立项目。当前部署已关闭小红书发布路由，并在其实际发布入口拒绝提交；采集结果经认证接口传入 Mac 的 Avalon。该云端部署修改不属于本仓库的 Mac 应用源码。
