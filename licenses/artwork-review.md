# Artwork review — source release

The public source tree contains only the six community sprite atlases with explicit MIT notices and pinned hashes in `src/renderer/src/assets/pets/sources.json`. The copied eight official OpenAI sprite sheets have been removed from the release source. Existing avatar IDs remain compatible through a mapping; employee identity and layout are unchanged.

Extracted Finder/MarginNote images, the Apple silhouette, the official Kali SVG and the Claude logo SVG have been removed from this release source. The replacement computer/book/shield and engine glyphs are original SVG code, licensed under the host Apache-2.0 terms. Sources are recorded beside the assets. This records replacement, not a grant from any vendor.

The former private Git history is retained locally. It is not the first public source snapshot. Public screenshots must be captured after these substitutions and reviewed for paths/credentials before publication.
