# Anexus 0.56.1

> 项目当前名称为 **Avalon**，分享地址：[Daijunfan/Avalon](https://github.com/Daijunfan/Avalon)。下文 Anexus 为当时的发布名称；安装包、命令和历史路径按实际记录保留。

修复 Pi 任务退出时可能带走整个 Core 的问题，并把宣传素材改成按 Company、Messages、Plan 保存的真实运行图库。

## Pi 超时与取消

Pi 在任务超时或取消后会先关闭输入，再等待子进程退出。如果此前发出的工具请求在这段时间返回，旧逻辑可能尝试向已关闭的输入回包，抛出未处理异常，使其他工作中的 Core 一起退出。

现在关闭动作开始时即标记连接关闭，复用已有的回包判断停止发送迟到结果。没有改变任务结果规则：超时仍记录为 timed_out，取消仍记录为 cancelled，不将它们包装为成功，也不重放任务。

新增隔离回归覆盖超时和取消两个真实关闭时序：本地确定性 Pi/SSH 协议夹具先挂起 Core 工具，等 Pi 输入关闭后才返回。验证 Core 仍可访问、任务保持失败/取消状态、没有伪造结果文件或成功回复，并能继续下一轮 Pi 任务。回归已接入常规 Core 测试集合。

## 三视图素材

按用户最新要求，停止以帖子为单位组织图片。当前本地素材目录为 `宣传素材_Anexus_三视图/`，包含 Company 7 张、Messages 11 张、Plan 10 张，共 28 张竖版截图，以及可点击原图的图库、逐图说明和文件校验清单。此前按帖子制作的版本移入本地 artifacts 保存，不作为当前素材交付。

所有图片来自实际应用界面。没有生成或替换消息、员工头像、工作状态、任务结果；没有把局部气泡重新拼接成虚构界面。26张重点画面按1024×1365完整竖屏取景，2张工作瞬间保留1100×1365原始截图。重复图、原文与总结错配图、关键回答截断图和空白周规划被排除。

四个真实群聊场景包括：

- 周末读书会：秘书安排六人90分钟活动，员工提出问题和流程。
- 周末出游：策划给600元预算和建议时间表，研究员核对总额与人均，设计员提供群通知结构。
- 资讯编辑部：研究员解释选题价值，校对检查夸大风险；原先仅阅读的成员可在后续被点名加入。
- 产品上线筹备：设计给首屏文案，校对提出首次使用时的待验证步骤，不宣称产品已上线。

Company 展示团队关系、三种引擎、真实工作气泡和绿色通信连线；Messages 展示秘书分工、选择性公开回复、图文新闻及其真实AI解读；Plan 展示同一批员工负责的10项真实计划、日历、看板、规则和执行历史。员工资料进一步显示同一人在群组和计划中的关联。

## 实拍与验证范围

实拍在独立工作空间运行5名员工，使用Claude Agent、Pi、Cline三种引擎。秘书实际创建4个群并分派工作，公开回复来自模型调用。新闻正文、图片、作者、时间与原链接取自已有公开来源，专题保留“原文转载”标记；解读由真实提问触发。

本轮未新增跨云主机演示。绿色工作截图中的订阅由摄影程序以秘书授权身份查看真实忙碌员工的进度，不把它说成模型自行选择的动作。更早版本的Linux/Windows远端实测记录保留在0.56.0说明中。

计划实拍有两次手动执行成功和一次物品清单超时；超时任务没有生成可确认的交付文件，不计入成功。拍摄后10项自动调度均已暂停，5名员工空闲，场景、消息与历史保留，避免继续消耗模型额度。正式用户数据中没有新建这些演示员工。
