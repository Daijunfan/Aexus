# 0.57.0 — 频道协作与多工作区

## Message 协作

群组和频道使用独立的 Owner / Admin / Member 身份。成员增删与管理员任免分别处理，降级保留成员身份与工作区；Owner 受保护，权限操作带修订检查和真实操作者记录。Company 职位不自动获得会话管理权。

每个频道成员可以单独设置新增帖子阈值、提示词及启停状态。计数只认新帖，排除重复提交、编辑及讨论消息；执行保留准确批次、分页原文和真实状态，支持重启恢复和授权撤销。按帖触发、定时固定正文通知与 Plan 的接口、记录和状态保持独立。

## 工作区和文件

`workspace.catalog` 返回本人 Company 和所有 Message 成员工作区的实际路径、位置及权限，不强制任务的存放位置。`conversation.entry` 提供完整已存公开内容与附件；`conversation.download` 把附件复制到本人选定的工作区，校验大小和可用的 SHA-256，保留共享原件及已有文件。

普通 Agent 完整操作自己的成员子目录。实际加入会话的 Company Secretary 可以额外维护根目录直属文件，仍不能写其他成员目录。

文件工作台支持按 Company / Messages / Plan、团队、员工、会话、文件类型及存储位置筛选；显示真实归属，使用应用内目录定位，修复频道图片引用与异步编辑冲突。

## 界面

频道管理共用成员与职位、通知、帖子计数三个入口。文档支持选择 Agent 及其目标工作区后复制。频道讨论头像位于气泡外，原始文章的来源头像仍位于文章内。

## 升级

沿用已有应用身份、数据目录、员工原生会话、插件版本和绑定工作区。旧频道管理员保留，升级不会自动指定 Owner、创建计数规则或新增 Plan 排期。完整接口见 `docs/MESSAGE_COLLABORATION.md` 与 `docs/FILES_WORKBENCH.md`。
