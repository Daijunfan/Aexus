# 宣传参考素材

这里保留了旧独立 Aexus 的小红书海报、文案、可编辑渲染源文件及界面素材，供新版 Aexus 宣传参考。

- `Reference/publish`：20 套主题，每套含 6 张海报、3 张界面图及文案。
- `Reference/creative-source`、`blueprint-source`：HTML、SVG、图表和文案源文件。
- `Reference/live-views`：界面图片、视频与动图。
- 其余目录保留历史设计与品牌素材。

这些素材记录旧版本功能；发布前请按当前 Aexus 的实际功能和界面更新。`manifest.json` 记录复制后逐文件核对的 SHA-256。
