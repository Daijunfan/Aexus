# 让AI工作有自己的节奏

## 可复制的正文

把下一次工作，写成一条清楚的规则

任务示例：明天下午整理资料、每周五汇总进展、指定频道有新帖就分析。三项工作的时间规则不同，但都在 Plan 里查询、修改、暂停和查看实际执行。

这组图讲清楚：

- 一次任务：指定一个实际执行时刻
- 重复工作：按间隔、周或月保存节奏
- 事件响应：新帖或显式信号成为起点
- 同一 Plan：查询、调整和历史统一管理

可以先这样交代：

> 帮我安排三件事：明天下午整理项目材料，每周五汇总本周进展，以及指定频道出现新帖子时做一次要点分析。都放到 Plan 中。

先安排一个你每周都要做的小任务，确认结果后再扩展自动化。

收藏 Avalon，把“下次记得做”改成一条清楚的 Plan。

项目入口：https://github.com/Daijunfan/Avalon

喜欢这套工作方式，去 GitHub 给 Avalon 点个 Star ⭐

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
