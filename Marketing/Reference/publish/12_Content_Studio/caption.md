# 让AI小队帮你做内容

## 可复制的正文

把创作做成流程，让每一段都接得上

任务示例：为一个产品准备一周内容。资料员工确认事实，写作员工提出面向新手的选题和初稿，检查员工核对出处与过度承诺；你选择最终方向，再按自己的平台流程发布。

这组图讲清楚：

- 受众优先：先说明内容给谁看
- 事实起步：从产品材料与来源提取事实
- 分工写作：资料、初稿和检查分别处理
- 版本保留：选题、稿件与意见留在工作区

可以先这样交代：

> 帮我准备一周的内容选题。资料员工整理产品事实，写作员工提出面向新手的表达角度，检查员工标出需要核对的内容。把选题与初稿存到工作区。

先给小队一份现有介绍，要求三个不同受众的选题角度。

收藏 Avalon，让下一次内容创作先有一支协作小队。

项目入口：https://github.com/Daijunfan/Avalon

喜欢这套工作方式，去 GitHub 给 Avalon 点个 Star ⭐

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
