# 把本机和云主机连起来

## 可复制的正文

机器可以分散，工作仍然可以组织在一起

任务示例：本机整理资料，已登记的 Linux 主机处理项目目录中的开发，另一工作环境检查结果。Team 绑定实际位置，桌面或浏览器连接同一认证 Core。

这组图讲清楚：

- Mac / Win：主要桌面使用方式分别支持
- Linux Web：Core 后端与浏览器访问分开
- SSH 工作区：Team 绑定实际主机和目录
- 统一入口：在同一工作台跟进消息和计划

可以先这样交代：

> 帮我组织一个跨主机项目：本机负责资料和检查，指定 Linux 主机负责项目目录中的实现任务。按现有引擎支持的方式连接工作区，并在群组里汇总进展。

从登记一台 SSH 主机、绑定一个项目目录开始，先验证一个具体任务。

收藏 Avalon，把下一次跨机器协作组织得更清楚。

项目入口：https://github.com/Daijunfan/Avalon

喜欢这套工作方式，去 GitHub 给 Avalon 点个 Star ⭐

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
