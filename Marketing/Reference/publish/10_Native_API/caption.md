# 让Agent直接操作工作台

## 可复制的正文

让 Agent 操作业务，不必依赖按钮位置

任务示例：让秘书查找指定项目的计划，列出当前任务与可调整项，再修改已确认的目标并回查。命令发现、身份校验与业务执行经过公开 Core 入口。

这组图讲清楚：

- 命令可发现：公开文档与参数 schema
- 原生可调用：使用真实身份提交命令请求
- 同一 Core：GUI、CLI、工具复用实现
- 结果可回查：查询状态、历史和实际文件

可以先这样交代：

> 读取当前公开 API，帮我找到指定团队的任务，列出可调整项，再按我确认的范围更新计划并回查结果。使用真实 ID 与当前权限。

从 api.list、api.describe 和一个只读查询开始，再组织实际工作流。

给 Avalon 点个 Star，把 Agent 工作流建立在可组合的公开接口上。

项目入口：https://github.com/Daijunfan/Avalon

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
