# 四种Agent一起协作

## 可复制的正文

你喜欢的 Agent，也能进入同一支团队

任务示例：同一个开发目标，由已配置的 Codex、Claude Code、Cline 和 Pi 员工协作。各自保留原引擎，以 Team、群组、任务与文件承接实现、检查和资料工作。

这组图讲清楚：

- Codex：App Server 接入与原生身份
- Claude Code：Claude Agent SDK 接入
- Cline：ACP 接入与已支持工作区
- Pi：RPC 接入与已支持工作区

可以先这样交代：

> 帮我建立一个跨引擎开发小队。分别使用我已配置的 Codex、Claude Code、Cline 和 Pi 员工，把实现、检查、资料整理和汇总职责写清楚。

先用两种已配置的引擎协作一个小任务，熟悉后再扩展队伍。

Star Avalon，让你喜欢的 Agent 不再各自为战。

项目入口：https://github.com/Daijunfan/Avalon

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
