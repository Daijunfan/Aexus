# 把读写管理连成工作流

## 可复制的正文

阅读、笔记与主机能力，接回同一个目标

任务示例：先阅读一份资料，再把关键观点写进笔记工作区，必要时连接已登记主机处理项目。Margin Reader、MiniNotion、Cloud Hosts 各承担一段，秘书协助把入口与任务接起来。

这组图讲清楚：

- Margin Reader：阅读、摘录与资料整理
- MiniNotion：笔记、数据库与知识组织
- Cloud Hosts：SSH、连接状态与桌面入口
- 公开接口：插件按当前身份与工作区使用

可以先这样交代：

> 帮我把这份资料的阅读和整理连起来：用合适的阅读入口处理文档，在笔记工作区归纳关键观点，再把研究问题与资料位置发到协作群。

先用一份资料串起阅读与笔记，再按需要加入其他插件能力。

给 Avalon 点个 Star，搭一张能读、能写、也能连接工作的桌子。

项目入口：https://github.com/Daijunfan/Avalon

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
