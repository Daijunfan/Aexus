# 今天搭起第一支AI小队

## 可复制的正文

第一支团队，不必从一套庞大流程开始

第一次体验示例：准备一个可用引擎、一份已有资料和一个小目标。用户创建 Secretary，让秘书安排成员与入口；通过三个视图跟进一次真正有文件交付的任务。

这组图讲清楚：

- 准备引擎：程序、模型与认证按实际准备
- 创建秘书：用户指定 Secretary 角色
- 交代小事：用一份资料或一个小功能开始
- 检查结果：看三个视图和第一份实际产物

可以先这样交代：

> 帮我搭起第一支小队。先整理我给的资料，告诉我分工、文件位置，以及如何在 Company、Messages、Plan 中继续跟进。

打开项目 README，准备所需环境与模型配置。然后告诉秘书：帮我把这个小任务组织起来。

现在去 GitHub 点个 Star。你的第一支 AI 小队，可以从 Avalon 开始。

项目入口：https://github.com/Daijunfan/Avalon

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
