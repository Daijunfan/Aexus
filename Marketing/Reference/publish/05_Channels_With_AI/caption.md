# 新闻和AI解读放一起

## 可复制的正文

信息不是看完就走，还能接上分析与行动

任务示例：建立一个行业观察频道，接入指定来源。原文、PDF 等资料与 Agent 解读放在同一工作路径上；你先读重点，再打开原文继续核对或追问。

这组图讲清楚：

- 原文可见：标题、来源与内容入口保留
- 文件可辨：文件名、大小和预览帮助定位
- Agent 解读：围绕材料提取重点与问题
- 继续追问：需要时回原文继续核对

可以先这样交代：

> 帮我建立一个行业观察频道。接入我指定的来源，让分析员工整理值得关注的变化，并在频道里发布摘要、原文线索和待核对问题。

先接入一个你真的关心的来源，再让员工围绕一篇文章做解读。

Star Avalon，让下一次刷到的信息，接得上下一步理解。

项目入口：https://github.com/Daijunfan/Avalon

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
