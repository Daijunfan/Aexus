# 把文件交接变得清楚

## 可复制的正文

AI 接力的下一棒，需要一份真实文件

任务示例：资料员工把研究笔记交到共享位置，检查员工再取到自己的工作区继续处理。群消息说明背景，实际文件承接完整内容，文件树与资产入口提供查找线索。

这组图讲清楚：

- 原始材料：文件名、用途和版本保留
- 研究笔记：保存这一步的实际工作产物
- 共享位置：在授权范围内给下一位输入
- 检查文件：检查意见继续成为工作材料

可以先这样交代：

> 把这份资料交给整理员工，保存一份研究笔记到工作区。完成后将适合共享的产物放到共享文件位置，再让检查员工阅读并列出修改意见。

从一份 Markdown 笔记开始，完成一次员工到共享区、再到另一员工的交接。

收藏 Avalon，让下一次 AI 接力真正接得住文件。

项目入口：https://github.com/Daijunfan/Avalon

喜欢这套工作方式，去 GitHub 给 Avalon 点个 Star ⭐

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
