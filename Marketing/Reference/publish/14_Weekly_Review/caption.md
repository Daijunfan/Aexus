# 把周报拆成平时的小工作

## 可复制的正文

一周的工作材料，变成下一周的起点

任务示例：每周五整理一个项目的进展。以实际工作记录和文件为材料，按完成事项、未解决问题、下周计划三部分形成初稿，并保留能继续查看的产物位置。

这组图讲清楚：

- 平时材料：阶段成果与问题平时留下来
- 每周规则：Plan 保存明确员工与时区
- 周报初稿：完成、问题、后续分开整理
- 下一步：把真正需要继续的工作写清楚

可以先这样交代：

> 每周五帮我汇总这个项目的进展。按完成事项、未解决问题、下周计划三部分整理，注明工作文件位置，保存成可修改的周报初稿。

先让员工整理一次已有项目材料，再把合适的口径保存成每周任务。

收藏 Avalon，让下一份周报有材料、有问题、也有下一步。

项目入口：https://github.com/Daijunfan/Avalon

喜欢这套工作方式，去 GitHub 给 Avalon 点个 Star ⭐

最后三张是实际运行界面：Company 看人员与协作，Messages 看群聊或频道，Plan 看任务安排与执行记录。
