# 新闻和AI解读放一起

信息不是看完就走，还能接上分析与行动

任务示例：建立一个行业观察频道，接入指定来源。原文、PDF 等资料与 Agent 解读放在同一工作路径上；你先读重点，再打开原文继续核对或追问。

这组图讲清楚：

- 原文可见：标题、来源与内容入口保留
- 文件可辨：文件名、大小和预览帮助定位
- Agent 解读：围绕材料提取重点与问题
- 继续追问：需要时回原文继续核对
