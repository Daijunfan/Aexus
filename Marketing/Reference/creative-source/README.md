# Avalon 工程蓝图密集创意版宣传库

本目录为 2026-10-04 新建的独立发布库，不覆盖已有宣传文件夹。

- 20 个主题，每篇 6 张，共 120 张 PNG。
- 竖版 3:4，1440 × 1920，适合按组查看和发布。
- 每篇包含优势总览、六步工作原理、角色与交接、处理条件、具体任务交代和起步行动；补充输入输出、交接矩阵、文件示例及常见问题。
- 纯文本与矢量图形，无应用截图、无生成图片。
- Graphviz 生成系统流程图、标准流程图与 DFD；HTML / CSS 完成工程图纸排版。

## 怎么使用

1. 打开 [浏览目录](index.html)，选择主题。
2. 使用该目录内的 01.png 至 06.png，顺序保持一致。
3. 复制并按需要修改 [发布文案](发布目录.md)中各主题目录的“发布文案.md”。
4. 分享地址统一使用 https://github.com/Daijunfan/Avalon。

每张海报保留同编号 HTML，各主题保留 Graphviz .dot 与 SVG 图形源码；根目录保留文案、标题和生成脚本。验收报告列出逐张检查与旧材料保护结果。

## 风格

工程蓝图网格、黑色标题、方形框架、编号读图路径、蓝色工作线、绿色交付线、灰色辅助信息、文档图号与图纸栏。保留工程图纸的秩序感，加入 Avalon 标识、主题色、重点标题、优势卡片和任务主线。信息通过操作步骤、数据表、交接关系及问答展开。
