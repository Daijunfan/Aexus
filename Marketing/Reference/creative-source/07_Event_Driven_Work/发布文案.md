# 让AI按事件行动

让变化触发工作，让记录说明发生了什么

任务示例：行业频道出现一篇新文章，分析员工提取要点并写下问题。任务平时等待事件；冷却、时段与当前状态共同决定本次是否执行，实际结果留在 Plan 中。

这组图讲清楚：

- 等待变化：不需要虚构下一次触发日期
- 指定来源：频道新帖与 signal 有明确身份
- 节奏可调：冷却和工作窗口符合需要
- 实际记录：执行、忽略与跳过分别保留

可以先这样交代：

> 当行业观察频道出现新帖子时，让分析员工提取三个重点并写下待核对问题。设置适合这个频道的冷却时间，在 Plan 中保留任务与执行记录。

选一个更新频率适中的频道，从一条新帖分析规则开始。

给 Avalon 点个 Star，让下一条新信息触发下一次工作。
