# 小红书发布文案

## 标题

Core 持续运行，浏览器随时接入。

## 正文

Avalon 可以把界面和执行分开：Core 放在自己的固定主机上，桌面或浏览器连接它。Linux Core / Web 后端适合持续工作，另一台电脑只负责查看、上传材料和读取结果。当前是单用户自托管模式；Core 必须保持运行，一个数据目录只启动一个 Core。

项目：Avalon
主页：https://github.com/Daijunfan/Avalon
