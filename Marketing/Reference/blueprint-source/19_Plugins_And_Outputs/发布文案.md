# 小红书发布文案

## 标题

让 Agent 的成果，留在可继续工作的地方。

## 正文

Agent 的成果可以进入更适合继续工作的工具。Avalon 包含 Cloud Hosts、MiniNotion 和 Margin Reader：连接主机、组织页面数据库、阅读和整理资料。员工通过授权插件接口操作，保存后回读实际内容，让结论留在可编辑、可复用的地方。

项目：Avalon
主页：https://github.com/Daijunfan/Avalon
