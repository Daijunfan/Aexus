# 这次为什么不需要修改插件代码

MiniNotion 已有页面和记录的图标、封面功能。旧宣传截图中的六条记录没有配置 icon/cover，也没有正文，所以都显示默认文件图标和占位预览。

这次直接通过插件公开 API 为演示内容设置不同的图标、封面和正文，再从实际 App 重新拍摄。正式封面采用插件自身的窄窗口两列布局，没有修改 CSS 来伪造产品画面。

已验证：

- 六张卡片的图标、封面都不同，无默认文件图标。
- 页面可通过图标选择器修改，CLI 立即读取到相同值。
- 关闭、重开插件后，图标和封面保持。
- 拍摄使用隔离目录与隐藏窗口，没有修改真实笔记，没有模型调用。

正常使用时，打开页面，点击标题上方的图标即可更换；点击“添加封面”或“更换封面”选择样式。对应 API 是 `page.create`、`page.update` 和 `page.get`，例如：

```bash
agents plugin call mininotion page.update \
  --team '你的笔记团队' \
  --params '{"pageId":"页面ID","changes":{"icon":"🎨","cover":"dusk"}}'
```

本次更新正式配图与文案为十篇、每篇三张，共三十张。`内容去重清单.md` 列出每张独立展示的内容；原始截图不跨成品复用，未通过换标题或换背景重复发同一画面。
