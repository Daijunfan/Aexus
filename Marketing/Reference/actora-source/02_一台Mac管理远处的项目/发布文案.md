# 一台Mac，管住散落在各处的项目

项目散在几台机器上，最烦的是：刚想做事，又要先想“它到底在哪”。

我把它们收进了同一张办公室地图。一个项目一个 Team，云主机、操作系统、负责的 AI 同事都能看见。本地 Agent 也能通过远端工具处理云端项目。

我想把“找机器、找项目、找会话”的来回切换，变得简单一点。你现在有几个地方在同时开工？

配图为实际应用界面；文案、任务与云主机连接状态采用隔离的演示数据，不代表实时模型执行结果。
