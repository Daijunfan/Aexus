# 小红书首发 10 篇

共 31 张正式图片：01 文件夹有 4 张，其余 9 篇各 3 张。每张图与全部预览图都已附上完整 GitHub 地址：

https://github.com/Daijunfan/Agents-Company

01 主封面为 3600 × 4800；01 的 02～04 为 4320 × 3440；其余图片为 1440 × 1920。原始截图和制作素材不作为帖子配图。

01 封面展示真实的 Governor → 6 位 Manager → 18 位员工协作。任务是每位员工写一首五言绝句；既有团队位置与人员保持不变，绿线来自实际应用，路径和消息已隐藏。

本次封面使用 Codex、Claude Code、Cline 和 Pi 四种真实运行的引擎；Claude Code、Cline、Pi 使用 DeepSeek Flash，关闭思考。选用画面包含 20 条真实任务协作绿线，18 位员工的诗作已通过工作区 API 读取验证。

其余图片为已有功能演示，示例任务与主机状态不作为实时模型运行或真实连接的证明。各图保留相应演示说明。

使用范围是 Mac 桌面、Windows 桌面，以及 Linux 后端搭配另一台主机的浏览器。日常主要在本地 Mac 验证。

每篇文件夹中的 `发布文案.md` 可复制使用，图片按文件名前面的数字顺序上传。建议先发 01、02、03，再穿插笔记、项目与插件场景。

`00_十篇封面总览.jpg` 和 `预览_*.jpg` 用于挑选、检查；`小红书_10篇_发布包.zip` 包含正式图片、文案和预览；`交付校验.json` 记录尺寸与文件校验值。
