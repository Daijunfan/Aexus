# 我让Codex和Claude做了同事

我经常在 Codex 和 Claude Code 之间切换。后来想：能不能让它们都变成工作台上的“同事”？

于是有了这两位。保留各自的引擎，用同一套团队和会话界面组织工作。名字、工牌、工作状态都看得见。

我很喜欢这种感觉：熟悉的能力，长出了可爱的外形。你会把它们安排成什么搭档？
