# 我给 AI 开了家公司

这次，我只对 Governor 说了一句：
“通知你的所有 Manager，让他们手下的员工每人都写一首五言绝句。”

接下来，6 位 Manager 把任务交给各自的员工。25 位 AI 同事，分布在 Mac、Windows、Ubuntu、Kali 团队中。流动的绿色连线，让协作过程一眼可见。

本次封面使用 Codex、Claude Code、Cline 和 Pi 四种真实运行的引擎；Claude Code、Cline、Pi 使用 DeepSeek Flash，关闭思考。选用画面包含 20 条真实任务协作绿线，18 位员工的诗作已通过工作区 API 读取验证。

Agents Company 把团队、对话、文件、终端和插件放进同一间 AI 办公室。

支持三种使用方式：Mac 本地、Windows 本地，或者 Linux 服务器运行后端、另一台电脑用浏览器访问。我平时主要在 Mac 上使用。

封面来自真实任务运行时的应用截图；团队位置与员工保持原样，路径和消息已隐藏。02～04 是此前的功能演示截图，连接状态和示例任务不代表本次实时执行。所有连线都由应用渲染。

开源地址：https://github.com/Daijunfan/Agents-Company

# 给每页笔记一个自己的样子
