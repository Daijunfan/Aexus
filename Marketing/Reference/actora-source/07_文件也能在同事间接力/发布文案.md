# 让文件在AI同事之间接力

一个项目常常会经过好几位伙伴：这位整理资料，那位写代码，下一位再检查。文件一散，交接就容易乱。

所以我给工作台加了中转站。文件可以拖进去，再交给下一处工作空间；TXT 和 Markdown 也能在这里直接打开编辑。

我想让“接着做”这件事，更顺手一点。

配图为实际应用界面；文案、任务与云主机连接状态采用隔离的演示数据，不代表实时模型执行结果。
