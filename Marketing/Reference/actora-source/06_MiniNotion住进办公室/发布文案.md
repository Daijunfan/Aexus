# 给每页笔记一个自己的样子

笔记越来越多，六个长得一样的白方块，真的很难找。

我在 MiniNotion 里给不同内容换上了各自的图标和封面：产品路线图、设计灵感、写作、发布准备、项目笔记、资料书架，一眼就能分清。点进去是能继续编辑的正文，任务也能切成看板。

它已经集成在 Agents Company 里，自己改、让 Agent 通过 CLI 改，都落在同一份内容上。独立插件，非 Notion 官方客户端。

配图为实际应用界面；文案、任务与云主机连接状态采用隔离的演示数据，不代表实时模型执行结果。
