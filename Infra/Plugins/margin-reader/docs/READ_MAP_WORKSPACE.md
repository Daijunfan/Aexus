# Margin Reader 0.9：文档与脑图

0.9.1新增文档与脑图并排、左右互换和宽度调整，仍只提供两类内容；见 [SPLIT_READING.md](SPLIT_READING.md)。下文保留0.9.0产品裁剪记录。

当前界面只提供两个主视图：**文档**和**脑图**。打开学习集后默认进入脑图；文档视图列出真实 PDF／HTML 等原件缩略预览。打开原件可以翻页、连续滚动、搜索、缩放和标注，随时通过同一组按钮返回脑图。

## 产品范围

移除卡片盒、学习大纲、复习／FSRS、牌组、学习仪表板、智能看板及笔记本／对照布局面板的用户入口。文档自身的章节目录保留为阅读导航，不构成第三个主视图。主题备注、图片、数学公式和原文来源继续在脑图中使用。

已有摘录、主题、笔记、原图、关系、历史和原始文件均保留。旧视图的打开会通过公开 API 切换到主题模式；不会删除旧学习数据。为旧文件导入和员工脚本兼容，底层接口中的 card ID 与 review 等旧方法保留；它们不创建已移除的前端面板。

## 无限视口

画布使用独立的本地 camera（平移位置与缩放），与主题坐标和原文页码分离。没有按内容尺寸截断的滚动容器，向左、右、上、下都可继续平移；不使用浏览器整体缩放。

| 操作 | 行为 |
|---|---|
| 触控板双指左右／上下滑动 | 横向／纵向平移画布；保留系统输入的惯性 |
| 触控板捏合、Ctrl/Cmd＋滚轮 | 以指针位置为中心缩放 |
| 拖动空白、鼠标中键、空格＋拖动 | 移动画布；Escape 取消当前拖动 |
| 适配 | 显示整张导图 |
| 点击缩放百分比、Cmd/Ctrl＋0 | 回到 100% |
| Cmd/Ctrl＋加减号 | 逐级缩放 |
| 双击空白 | 在当前位置建立独立主题 |
| 双击主题、空格 | 原位编辑标题 |
| Tab／Enter | 添加子主题／同级；中心主题按 Enter 添加主分支 |
| Cmd/Ctrl＋Enter | 插入父主题 |

视图缩放支持 0.01%–400%。相机可移出全部内容边界；主题持久坐标使用 ±10亿的数值安全范围，支持负坐标。这是数值处理上限，不是屏幕边缘。地图再次打开自动适配；同一窗口内切换文档／脑图保留相机状态，其他员工的读取不会修改本地相机。

低倍率总览采用合批图形表示完整主题，点击恢复可编辑细节。拖动大量子主题时保留完整模型和连线，只挂载附近的编辑元素，避免将所有节点变为拖拽卡片。搜索、导出、原文回源和命中查询不截断为屏幕内数据。

## 脑图功能

保留54种独立骨架、9个结构家族、15个方向、13套配色、混合分支布局、自定义层级样式、主题形状、外框、概要、关系、标记、公式和图片。常用操作集中在一行，次要操作放到“•••”菜单。查找只在需要时展开；不再常驻一整行学习工具。

骨架使用自主设计，不把数量相同当作与商业 XMind 逐像素一致的证明。官方原图参考记录、结构几何和原有设计验证继续保留。

## 阅读与原文关联

单击有来源的主题跳到 PDF／HTML 的原始位置，普通独立主题只选中。PDF 中取消标注保留相应主题及原图，删除主题另走可恢复删除。原图和文档仍使用各自的源版本校验。

阅读工具收纳到“标注”菜单。阅读区域使用完整主区域宽度，不保留已经退出的左右卡片分屏。

后台位置保存使用 `reader.position.set {activate:false}`，保存页码不抢回正在显示的脑图。员工主动调用时默认 activate:true，仍能把文档导航显示到相同授权窗口。`study.view.set` 的 documents/map 值让员工和界面切换同一主视图。
