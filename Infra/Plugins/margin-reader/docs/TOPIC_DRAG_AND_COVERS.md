# 主题拖放与完整资料封面（0.9.2）

## 操作规则

拖住主题A，移动到主题B的主体内再松开：B成为A的父主题，A的全部子主题跟随。目标边缘显示绿色框，指针旁明确提示“松开成为……的子主题”。目标主体的上沿、中间、下沿均执行同一种父子关系操作；同级排序只使用节点外侧的插入区。

默认移动工具和选择工具采用相同规则。旧的“拖绘父子关系”工具也统一为移动源主题到目标父主题，修复反向重排。按住Option/Alt可明确脱离为自由主题。“自由主题关闭邻近吸附”只禁止贴近外侧时吸附；明确拖进主题主体仍表示连接。

拖动普通节点或总览中的合批缩略节点时均使用同一模型命中检测。只移动选中的子树，保持原缩放比例。拖住真实空白处平移画布，中键是明确的画布平移操作；双指上下左右平移和指针中心缩放继续可用。释放、取消和外部版本冲突后不产生额外的原文点击。

拖到折叠的父主题会在同一次操作中展开该主题，避免新加入的分支立即隐藏。一次撤销同时恢复原父子关系和折叠状态。拖入自身或后代被拒绝；并发更新不覆盖新内容。独立子脑图边界继续保留其原有语义，不以重设父节点展开整本资料。

所有操作通过既有公开 `study.cards.move` 实现；新增可选布尔参数 `expandParent`，默认不改折叠状态。员工与界面使用同一版本校验和撤销路径。

```json
{"method":"study.cards.move","params":{"setId":"STUDY_ID","expectedRevision":1,"cardIds":["TOPIC_A"],"parentId":"TOPIC_B","expandParent":true}}
```

## 资料封面

文档主页改成紧凑封面架：完整PDF封面或HTML内容预览保持原始比例，不再裁成页首横条。去掉大卡片下方的空白填充，标题最多两行；格式、文件大小和PDF页数单独排列，路径降为文件夹提示，完整路径在提示文字中保留。

移除关联按钮仅悬停、键盘聚焦或触摸界面显示，点击仍需确认且不删除原件。原文变更与缺失有独立状态提示。无缩略图的格式显示清晰的纸张占位，原文件始终可按原能力打开。网格、列表、并排和窄窗口共用此组件。

预览仍由 `document.preview` 生成并受原有并发、内存、缓存和工作区权限限制。新增外观不解析第二份业务状态，不修改PDF、HTML、笔记或学习集关系。

## 原生产品参照与取舍

XMind官方主题文档说明主题层级可通过拖放调整，支持主题形状、分支样式、混合结构和撤销。保留现有54种自主骨架及设计能力，在主题层操作真实结构：
https://xmind.com/user-guide/topic-editing-new

MarginNote 4官方“移动、合并、重组”明确描述A拖到B，绿色“成为子卡片”提示后A成为B的子卡片，并且A的后代一起移动。这次采用同样清楚的源、目标和子树方向：
https://manual.marginnote.com.cn/mn4/mind-map-cards-move-merge-regroup/

XMind的自由主题可以自由摆放并重新接入结构：
https://xmind.com/user-guide/floating-topic

本插件在明确落入主题主体时优先采用用户的重设父节点意图，避免“自由”设置使手势失效；Alt保留显式脱离。没有引入拖动自动合并内容，也没有恢复已退休的卡片盒和复习界面。资料摘录、原文回源和笔记继续使用原有稳定身份。

参照可观察的操作与视觉组织，不宣称复制商用客户端全部私有算法、商业素材或逐像素兼容。

## 验收路径

`npm run test:topic-covers`：完整封面、真实鼠标重设父节点、选择模式、总览合批主题和整棵子树、取消及撤销。

`npm run test:deep-audit`：所有当前界面及原有Core回归。

`npm run test:agent-acceptance`：完整员工启动器与隐藏原生窗口，复用本轮节点拖放验证。

额外使用实际“横向移动”文库的隔离副本验证完整封面、已选中的来源主题改父节点、PDF第159/696页回源、左右并排，以及真实文库状态和原件字节未改变。最终运行结果以交付JSON与固定构建哈希为准。

本轮自动化使用鼠标／wheel事件；实体触控板人工操作、其他操作系统与长时间重媒体负载未由这些结果替代。
