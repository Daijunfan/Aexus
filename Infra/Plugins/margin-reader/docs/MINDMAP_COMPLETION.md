# Margin Reader 0.8.0：本地脑图设计、交互与导出

历史版本记录：当前0.9已收缩为文档与脑图，使用方式以 [READ_MAP_WORKSPACE.md](READ_MAP_WORKSPACE.md) 为准。


更新日期：2026-10-02。仅修改 Margin Reader 插件。实现与界面均使用同一授权工作区内的公开 Core API；浏览器不保存第二份导图。

## 使用入口

打开学习集，选择“主题脑图”。“骨架 / 配色”可搜索和选择54种骨架，按9个结构家族分组；“我的设计”保存自定义方案。“格式”修改当前主题及层级风格。“展开 / 折叠”“对齐 / 分布”“公式”“演示”和“导出”均在脑图工具栏中。

独立摘录之间没有父子关系时，可使用“整理成导图”显式创建中心。该操作保留摘录与原有子树，可一次撤销；打开文库不会自动重写知识关系。

## 设计系统

54种骨架分别配置结构、层级形状、线型、字体、边框及间距，真实布局与样式的联合输出经过唯一性检查。它们是独立实现的设计方案，不能仅凭数量认定与官方54套设计逐像素一致。

支持15个方向选项、同图混合结构、13套内置配色、2–12个自定义分支颜色、独立中心色、1–8层自定义样式、编号前后缀、31种主题轮廓。换配色保持所选骨架，重设视觉风格保留公式、自由定位和演示语义。

本地设计库通过 `study.mindmap.design.list/save/apply/archive/export/import` 管理。设计只携带样式，不携带卡片、原文路径或员工身份。导入先检查再应用；导入源文件和设计库版本均会校验。应用方案进入学习集撤销历史，存储重启后仍保留。

## 直接操作

拖动使用画布中的主题和当前缩放，不生成操作系统默认拖拽图片。完整分支跟随主题移动，大图使用有界临时图层显示整支轮廓；松开前展示父子关系或同级插入提示，松开后一次提交。Escape、失焦和指针取消清除临时层；并发修改拒绝旧请求，不自动覆盖。

启用自由调整主分支后可保持父子关系调整位置；开启灵活浮动可避免邻近边缘吸附；0.9.2起，明确落在主题主体内仍设置父节点，Alt可强制保持独立。智能辅助线按模型坐标吸附。浮动主题支持六向对齐、横纵均匀分布和恢复自动位置。宽度手柄与公式比例手柄使用共享测量，在松开时持久化。

| 操作 | 按键或入口 |
|---|---|
| 从中心建立主分支 | Enter |
| 建立同级／前一个同级 | Enter／Shift+Enter |
| 建立子主题 | Tab |
| 插入父主题 | Cmd/Ctrl+Enter |
| 编辑标题 | 空格或双击主题 |
| 提升一级 | Shift+Tab |
| 同级排序 | Option/Alt+上下方向键 |
| 复制、剪切、粘贴整支 | Cmd/Ctrl+C、X、V；主题模式粘贴到当前选中主题 |
| 建立独立自由主题 | 双击空白；或Option/Alt拖离已有分支 |
| 详情、原图与笔记 | 预览按钮／详情／F2 |
| 取消正在进行的直接操作 | Escape |

粘贴在开始时固定目标学习集、主题和版本。等待读取剪贴板时切换学习集会取消旧粘贴；已经提交的旧学习集结果不会抢回新页面。

## 动画、搜索与关系

按层级折叠、全部展开、结构调整时，节点及分支连接同步过渡；临时退场节点不进入业务状态，动画结束清除。退场节点的渐变和裁剪定义使用独立ID，避免消失或与现存节点冲突。渐细分支的填充轮廓、普通曲线的描边和配色同时进入动画层，过渡帧不会变成无填充／无描边的透明路径。真实指针或键盘操作前结束几何过渡，避免命中移动中的旧位置。系统减少动态、单图关闭动画和大量节点降级保留全部编辑能力。

输入搜索词、颜色或标签时保留导图拓扑，以高亮／弱化区分匹配结果；匹配导航可进入折叠分支。展开通过公开可撤销命令执行。关联线可自动避开其他主题，手动曲率控制保留；拖动端点主题时关系线和标签实时更新。

## 本地公式与导出

公式使用本地 MathJax 转为矢量路径，支持分式、根式、积分、矩阵及化学式。状态仅持久化LaTeX和比例，尺寸由Core重新计算，不信任调用者提供的尺寸或SVG。外链、HTML样式、递归宏和过长输入被拒绝，独立公式之间不共享用户宏。

SVG、PNG和矢量PDF使用同一几何、文字、关系、标记、图片及手写。PDF默认可选择和搜索文字；支持自动尺寸、A4/A3横向；字体缺字时明确报告，可选择图像PDF兼容模式。字体仅在本机读取并按导出需要嵌入，不分发原始字体文件。

修复进度环使用八位十六进制透明色造成的SVG 1.1导出失败：共享标记输出改为RGB和独立透明度属性，外部SVG资源禁令保持不变。复杂员工导图的SVG、PNG、PDF导出加入独立回归。

自动演示有逐主题、按分支、逐步展开三种队列，以及自动／网格／列表／图文／导图版式。按页容纳子主题，完整笔记在演讲者笔记保留，PDF导出多页矢量演示；PPTX保留可编辑文字、笔记、公式矢量图及兼容栅格。未将整页截图伪装成可编辑幻灯片。

## 验证

运行 `npm run test:mindmap-completion`、`npm run test:xmind`、`npm run test:deep-audit` 和 `npm run test:agent-acceptance`。通过结论以最终固定构建的日志及JSON为准。

覆盖54种骨架真实按钮应用、53主题复杂导图、125主题六层几何、10000主题总览与大分支拖动、公式及绑定图片、真实鼠标宽度调整、退出取消、剪贴板导航竞争、矢量PDF可搜索内容和PPTX独立办公软件渲染。原生窗口及主页面新建团队测试使用隔离目录和确定性模型协议，不调用真实模型。

## 范围与限制

单学习集最多10000主题、64层；大图总览和动画采用有界显示，业务模型、搜索、回源、导出保持完整。仅本轮实际运行的macOS环境算作设备验收，文字压力样本不替代长期图片、实体笔和跨平台实测。

本轮完成脑图设计与直接操作范围。商业原生加密／旧XML工作簿、未知私有扩展、甘特资源调度、账户、云同步和AI服务不构成这次视觉实现的通过项。截图参照和原图出处见 `XMIND_VISUAL_REFERENCE.md`；没有把官方素材打入运行包，也不宣称商业客户端逐像素兼容。
