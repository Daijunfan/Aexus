# Aexus 0.63.1 · Deep Research 1.6.0

## 研究流程

- 保留 Research Studio 1.5 的多 Agent 原生会话、三轮确认、可编辑计划、并行研究、来源核验、暂停/恢复、研究分叉、文档导入及 Word/PDF 等交付格式。
- 最终报告通过证据审查后还需主编和另一位独立研究员分别复审。独立审查拒绝时要求修订，最多两轮，未通过不交付中间稿。每项复审关联实际 Agent 任务和状态。
- 相同 URL 的网页内容 SHA-256 变化时建立独立来源快照，保留各版本摘录归属并提示版本差异；覆盖质量仍按不同 URL 计数，避免虚增独立网页数量。
- 支持从公开 HTML/文本与带文字层 PDF 独立核验原文、短引用、最终 URL 和内容指纹；公开 PDF 最大 8 MiB。导入的本地 Office/PDF 材料仍需经用户明确选择和独立准备流程（单次合计最多 4 MiB）。

## 进度与视图

- Infra 新增 `workflow.events`：每个研究保存最多 128 条**公开进度检查点**，含持久 revision、阶段、状态、完成步骤、来源数和百分比；支持 `afterRevision`、`limit`，继承工作流所有者及 Engine 作用域鉴权。
- Deep Research 工作台增加可恢复的研究趋势图、阶段时间、最近检查点历史、网页修订提醒和独立复审结果。进度是步骤覆盖，不代表准确率或预计完成时间。
- Company / Messages / Plan 顶部三视图导航保持等宽居中，支持窄窗口、不同显示密度与主题。

## Infra 与兼容

- 在已有 `workflow.prepare`、`workflow.fork`、`workflow.export` 基础上补齐事件接口、CLI 输入规范、Contract 定义及生成文档。
- 兼容 Deep Research 1.0–1.5 持久工作流；旧任务的新增事件历史需要新的实际检查点才能累积。
- 保留原有三个最终交付文件，并可额外生成已审查报告的 Word/PDF。研究分叉不会覆盖母任务，私人材料仅经明确同意复用。

## 验证与限制

`npm run typecheck`、`npm run contract:check`、`npm run test:deep-research`、Web/Electron UI 测试及 macOS 安装包校验。测试使用临时 Core 与确定性协议适配器，未调用付费模型，也未在所有第三方真实端点上进行旗舰产品对照。

实际研究能力受配置的模型、授权、网络连接与源网站可访问性限制。厂商专有工具和订阅/连接器能力未获授权时不会自动启用；当前没有证据声称全面达到所有旗舰 AI 官方服务的每一项功能。
