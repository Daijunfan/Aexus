# Aexus 0.61.0 · Deep Research 1.3.0

## 更新内容

- **PDF 双向支持**：研究入口可添加本地 PDF（≤8 MiB、≤80 页，且单份提取文字≤80,000 字符）；公开 PDF 也可作为独立核验来源，按可提取文字比对短摘录，按原 PDF 字节记录 SHA-256。沿用 SSRF/重定向和站点范围校验；扫描件、加密文件及登录墙不自动破解或 OCR。
- **实时工作流进度**：Infra 在原有已鉴权 `workflow:changed` 事件上新增 Contract 客户端订阅桥接，只做失效通知；Engine 发起有版本号的 `workflow.get` 读取，带单飞合并、丢事件低频轮询和离开页面自动解除监听。没有引入新的身份权限、命令或会话数据泄漏。
- **多 Agent 执行视图**：逐研究员显示模型、真实任务步骤、审批状态、已完成步数、带减少动态效果的进度轨和原生会话跳转。保持现有协作图、来源工作台、三轮确认、深度预算、暂停/修订/恢复及三个最终交付文件。
- **Web Infra 补全**：静态资源服务以 JavaScript MIME 提供 `.mjs` 工作线程资源，使浏览器可加载本地构建的 PDF Worker，不访问第三方 CDN。
- **Company 导航检查**：Web/Electron 的窗口布局测试确认顶部三个导航按钮等宽、相对窗口中心对齐，兼顾窄屏与右侧操作按钮。

## 兼容与恢复

Deep Research 1.3.0 保持 Contract v1；显式兼容既有研究工作流 1.0.0、1.1.0、1.2.0 检查点。原员工、原生会话、权限、审批和用户资料均不迁移。若需要回退，使用安装工具生成的旧版应用备份恢复；保留数据目录，需确认无新版专用任务正在执行。研究出口仍只有 `research-report.html`、`research-report.md` 和 `evidence.csv`，不会自动公开草稿。

## 验证与限制

验证命令为 `npm run typecheck`、`npm run test:deep-research`、`npm run test:deep-research-ui`、`npm run test:deep-research-desktop`、`npm run release:check -- --technical`。真实服务模型的深度研究会产生费用，确定性测试不调用收费模型。PDF 文本抽取取决于文档内可读的文字层；完成进度是工作流阶段与已完成步骤，不是报告正确率。此版不支持 OCR、云盘文件接入或公开发行版重新分发；素材审核项仍未全部获批。
