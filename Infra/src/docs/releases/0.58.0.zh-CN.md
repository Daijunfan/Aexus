# 0.58.0：文件文库与存储信息

本次只更新文件区域，保留0.57.0的Company、Message、Plan主界面及原有数据身份。

Files保留目录树，Assets提供可展开的大图标文库、真实文档封面、员工头像和主机系统标识。单击选择、双击打开，右键/双指点击提供信息、新建、重命名、复制粘贴、下载、回收与撤销。图标尺寸及显示方式按客户端记忆。

支持按视图、团队、员工、群组/频道、主机、文件类型和存储位置组合筛选，搜索嵌套文件与文件夹。同一员工的Company和Message工作区分别展示。物理路径默认隐藏，通过“查看信息”明确读取实际位置、大小、时间、权限和核验状态。

本地PDF、HTML、Markdown和图片预览复用已安装Reader的纯渲染模块，缓存、并发和输入均有上限；不会为了封面自动下载云端原件。API与CLI：assets.browse、assets.info、assets.preview，权限和文件操作沿用Core。

本地安装包为macOS arm64私有候选，既有第三方再分发审核状态保持不变，不进行公开发布。安装过程使用原安装器、正常退出旧APP、备份数据并测试实际二进制。独立源码验收27项通过；候选和安装后实测记录保存在artifacts/app-update-0.58.0/。
