# Aexus 0.60.0

## Deep Research 1.1.0

研究主编、证据研究员、反证研究员通过不同原生 Coding Agent 协作；可额外加入专题研究员。沿用已配置的模型，也可在研究入口为已选引擎指定模型。研究方案可编辑，完成证据检查与独立报告审查后才发布最终文件。

新增标准、深入、广泛三档研究预算；允许、优先、排除的网站与起始来源链接；最多六份有大小限制的 UTF-8 文本参考材料。材料仅作用户背景，不计为已核验网页证据。来源核验有限并发，访问前、DNS 解析与重定向都经过安全检查，严格来源范围不足时停止交付，不静默扩大范围。原生模型自身的浏览遵循任务指令，独立网页核验的网络限制不等于对第三方模型实施网络沙箱。

研究工作台展示实际任务完成数、来源/网站/发现数量、各 Agent 的原生会话状态及来源核验进度。提供来源搜索、类型筛选、摘录和 SHA-256 指纹、引用跳转、审查阻断项、分歧、缺口和活动记录。工作流百分比根据阶段和已完成步骤计算，不代表结论置信度或预计剩余时间。

支持明确暂停、保存研究修订、检查点续跑。只停止本研究拥有的原生消息，不打断其他任务。修订保留有效来源 ID 和员工身份，清除旧草稿，重新制定方案与审查。暂停状态跨 Core 重启保留，修订不会自动重新开工。

全屏报告预览支持来源筛选、打印、键盘关闭和焦点恢复；嵌入式报告禁止执行脚本，阅读控件由已打包的应用代码绑定。最终交付仍为 HTML、Markdown、CSV，可一次下载经哈希检查的 ZIP。

## Infra / Contract

新增 `workflow.pause`、`workflow.amend`，恢复接口接受失败和已完成清理的暂停任务。修订通过版本号与幂等请求 ID 防止重复或过期提交，同一任务的控制变更串行化。Engine 可明确声明已测试的历史版本兼容范围；Deep Research 支持从 1.0.0 的检查点继续。

Company、Messages、Plan 三个顶部按钮按所在 Infra 区域居中；狭窄区域把右侧操作移至下一行，避免遮挡和偏移。

## 验证范围与限制

新增策略、隐私、重定向、暂停、修订、版本兼容和并发控制测试；浏览器与隐藏桌面端执行完整交互验收。测试使用独立 Core 和确定性原生协议适配器，不调用付费模型，也不操作正式工作区。此类测试验证流程与安全边界，不能代替真实研究质量评测。

本版未新增云盘/邮件研究连接器、登录墙读取、PDF 文件解析或 DOCX/PDF 自动交付，也未承诺与所有官方旗舰产品逐项等价。模型可用性、浏览能力、费用及真实研究质量取决于用户已配置的服务。
