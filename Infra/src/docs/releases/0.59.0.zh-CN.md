# Aexus 0.59.0

本版汇总 Aexus 分层改造与业务 Engine 的当前源码，并将产品、仓库和安装名称统一为 Aexus。

## 产品与结构

- 顶层入口为 Engine 和 Infra；Company、Messages、Plan 继续位于 Infra，共用员工、会话、文件和调度。
- 新增独立 Contract 1.0.0：业务 Engine 通过版本化接口接入 Core，不直接访问内部数据库。
- 包含 Deep Research、Profile Improvement、PPT Maker 与 Workspace Audit。研究按阶段收集证据；简历引擎保留 Word 模板；PPT 引擎支持编辑和原生 PPTX 导出；审计引擎提供只读参考流程。
- Engine 资源绑定、CLI/HTTP 请求和事件流使用同一作用域，切换或解绑时撤销相应数据流。
- 浏览器复制窗口分配独立客户端身份，刷新保留当前窗口身份，避免不同窗口互相切换 Engine。

## 模型默认值

- 新建 Codex 员工默认模型为 `gpt-6.1-sol`，思考强度为 `high`。创建参数优先，已有员工保持原配置。
- Claude Code、Cline、Pi 的密钥继续分别加密保存在本机；用户可配置为同一供应商和模型，源码与安装包不携带个人密钥。

## 更名与兼容

- 仓库地址、当前 README、软件标题、应用程序和 CLI 主入口统一为 Aexus。
- 历史命令别名、应用身份、资料目录和员工身份保持兼容，更新不迁移用户的外部工作区。
- 安装完成后清理旧应用程序和过期安装包，保留用户数据。

平台验证以本次实际执行结果为准；macOS 本机安装不代表 Windows 或 Linux 安装验证。第三方资源的许可审查仍独立执行。

## 本次验证

- 核心/CLI 回归 93/93，通过作用域专项 9/9。
- PPT Maker 文档与工作流回归 49/49；Profile Improvement 回归 30/30。
- macOS 安装包验证覆盖新启动页、默认模型、原生终端、文件读写、三个插件及四个 Engine；在临时数据目录和隐藏窗口执行，不调用收费模型。
- 同一 DeepSeek 密钥在本机加密保存；供应商模型目录鉴权成功，未把私人配置写入源码。
