# Aexus 0.64.0 — Engine Orbit 与研究任务归档

## Engine Library
- 主页面改为中央启动舱和环绕式引擎卡片。使用固定可视窗口，没有上下滚动和 Load 按钮。
- 必须将引擎卡片拖入中央启动舱才能进入工作区。单击卡片不加载；键盘提供抓取和投放，触屏支持拖放。
- 保留引擎目录分页、刷新、加载失败恢复及原有跨引擎数据隔离。

## Deep Research 2.0：空白引擎
- 删除所有原有研究运行时、搜证、报告、文档处理、Agent 提示词、协作图与工作台，只保留五个空壳入口文件。
- 加载空壳不会创建或启动 Agent，也不再发起研究任务。用户旧历史研究不会自动丢失。
- Core 发现历史运行状态时优先标记停止，不恢复原有推理。

## Infra → Plan：历史研究任务
- workflow.list 支持分页、total 和 hasMore；workflow.delete 仅供旧 Deep Research 记录使用。
- workflow.cancel 核对每位研究员原生回执，精确中断所属回合并确认停止。回执不明则保留 pending，禁止删除。
- 研究 Agent 已空闲且无队列或后台作业时释放原生会话；其他工作中的 Agent 保留。员工身份、工作区与消息仍保留。
- 删除前完成停止，然后将工作流状态与报告原子归档到 workflow-deleted 目录。原件可恢复，重复删除幂等。
- Owner 权限及 Engine 作用域继续在 Core 内核验。

## 验证
使用隔离 Core 和模拟原生协议，覆盖研究停止和删除、重启一致性、网页拖拽、键盘辅助、响应式布局以及其他 Engine 协作。无需付费模型或生产账号。macOS 以实测报告为准，Windows/Linux 仍需对应平台验证。
