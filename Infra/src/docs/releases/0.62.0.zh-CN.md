# Aexus 0.62.0 · 多 Agent 研究工作台与文档交付

## 新增与优化

- **多 Agent 协作进度**：协作图按持久化的原生任务记录显示各研究员的已完成任务数、任务进度和状态；未分派时显示等待状态，暂停、待审批与失败采用对应视觉提示。使用可访问的进度条和减少动态效果设置。工作流整体百分比仍按阶段、完成任务与已核验来源计算，不代表模型置信度或剩余时间。
- **研究素材**：增加由 Core 验证和抽取的 TXT、Markdown、CSV、JSON、PDF、DOCX、XLSX、PPTX 输入。原始文件大小、解压体积、页数、文本长度及扩展名受到限制；不运行 Office 宏、公式、外部引用或 OCR。保留旧版已抽取文字的 PDF 背景材料兼容性。
- **研究成果**：完整审查的报告可导出可编辑 Word 和可选中文字的 PDF；保持 HTML、Markdown 和证据 CSV 原有交付。下载前核对字节长度与 SHA-256；导出不额外触发模型调用。后续追问建立新的研究，关联原研究并在用户选择时复用私有背景材料。
- **证据严谨性**：核验完整提交摘录，防止仅凭有效前缀通过带虚构后缀的证据；保留网页和 PDF 原件校验、来源域名限制、Agent 贡献和逐摘录归属。
- **Infra/Contract**：研究素材准备、Word/PDF 导出和后续研究流程纳入已鉴权的 workflow API、命令目录、CLI 及 Manager 文档；沿用既有身份、工作流版本和权限边界。
- **Company 视图**：三个顶部视图按钮按完整窗口中心对齐，显示宽度受限时保持可见并避开右侧操作按钮，适配 Electron、Web、窗口缩放和响应式侧边栏。

## 测试

- `npm run typecheck`、`npm run build`、`npm run test:deep-research`、`node Infra/src/test/deep-research-studio-test.mjs`、`node Infra/src/test/deep-research-atlas-progress-test.mjs` 和 Web 端 `npm run test:deep-research-ui` 已通过。
- Company 定位测试覆盖多个实际 Electron 窗口宽度；桌面窗口存在最小尺寸限制。发布包与安装须独立验证，不以开发构建代替。
- 研究验收使用模拟来源和确定性 Agent 适配器，未证实所有第三方旗舰 AI 服务的完整能力一致性。

## 已知边界

不包含扫描件 OCR、任意付费资料的访问、第三方云盘原生连接器、所有前沿模型的自动订阅或专有能力复刻。具体模型能力取决于本机已授权的 Codex、Claude、Cline、Pi 等适配器及各服务协议。素材再分发审核项目仍处于待完成状态；此版仅作为本地开发候选包，不应作为获得公开分发授权的正式发行版。

## 升级

保留 `~/AgentsCompany` 数据目录与既有员工/会话身份。通过项目自带的 `npm run install:mac -- --source /path/Aexus.app` 安装；安装器会拒绝替换正在运行的应用，并在变更前备份旧版和必要的会话元数据。升级前确认没有正在运行的研究、审批或其他开发任务。
