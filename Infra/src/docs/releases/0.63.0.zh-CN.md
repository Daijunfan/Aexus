# Aexus 0.63.0 · Research Studio

## 研究工作台

Company、Messages、Plan 三个按钮根据整个工作窗口的实际中心定位。页面缩放、插件侧栏和文件抽屉纳入计算；空间不足时限制在可用区域，避免覆盖操作按钮。三个按钮保持等宽，保留键盘操作及原有团队视图菜单。

Deep Research 1.5.0 保留独立研究员、研究主编、反证路线、可编辑方案、三轮确认、来源核验、审查、暂停修订与断点恢复。新增文档材料导入、Word/PDF 按需导出和关联原报告的后续研究。工作台显示实际阶段、核验数量、各 Agent 的来源贡献、证据路线和待处理问题；进度不表示正确率或剩余时长。

## 文档与交付

支持明确选择的 TXT、Markdown、CSV、JSON、PDF、DOCX、XLSX、PPTX 文件。单次原始内容合计不超过 4 MiB；最多六份背景材料，总文字上限 200,000 字符。PDF 提取文本层，Office 提取已保存文字、表格和单元格结果；不运行宏、公式或外部数据连接，不执行 OCR，不声称解读未读取的图片或图表。截断、空白页和提取限制直接显示。

原 HTML、Markdown、CSV 三件套保持不变。最终报告通过审查后，可额外生成带可点击引用的 Word 和分页 PDF。Word 保留可编辑段落、目录、对照表与来源；PDF 包含证据分布图、页码和来源链接。客户端与 CLI 保存前核对 SHA-256 与字节数。字体来自运行主机，不随源代码分发；缺少所需字形时 PDF 导出明确失败，可继续使用 Word 或 HTML。

后续研究创建新的工作流和原生员工，记录父报告 ID 与修订号，重新核对来源时效。原报告及其文件不被覆盖；私人参考材料仅在用户明确勾选后复用。

## Infra / Contract

新增 `workflow.prepare`、`workflow.export`、`workflow.fork`。前两项仅处理明确提供的文档或已完成报告，不获得 Infra 调用客户端，不启动模型。后续研究沿用认证调用者、幂等键、版本检查及原权限；父子关系由 Core 写入。文档解析和排版运行在有资源与超时限制的独立线程。

Engine 依赖保留在各自包和锁文件中；开发初始化、CI 和桌面打包统一准备生产依赖。打包显式携带 Engine 运行库与物理工作线程路径，不能依赖开发机源码目录或全局模块。

修复仅匹配截断摘录导致未核实尾句被接受的问题；先验证完整提交摘录，再生成短展示片段。公开 PDF 可独立核验文本层并记录页码。丢失回执时，暂停先恢复并保存确切任务编号，等待该任务或审批回合停止，保留无关任务。

## 验收范围

使用临时 Core 数据、确定性原生协议、隐藏 Electron 与真实文件格式检查。详细通过、失败、跳过和安装结果保存在本次本地验收记录中。测试没有调用付费模型，也未用生产员工进行测试；协议验收不能替代真实主题的研究质量评估。Windows/Linux 的实际结果需要在对应平台单独确认。

本版没有把各厂商的商业产品、订阅或未授权连接器接入当前应用。授权云盘/Gmail/Notion 的直接检索、扫描件 OCR、图片与复杂图表理解、厂商专属视频/音频生成等仍需独立适配和用户授权。多 Agent 数量和来源数量均不构成事实正确性的保证。
