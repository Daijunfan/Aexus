# Agents Company 0.55.0 更新说明

> 项目当前名称为 **Aexus**，分享地址：[Daijunfan/Aexus](https://github.com/Daijunfan/Aexus)。以下保留当时的发布名称和实际验收记录。

本版整合文件与资产中心、Telegram 文档采集与显示、Company 导航和定位、会话目录与群组治理、Secretary/Plan API，以及已完成的 Margin Reader 0.9.4 和 MiniNotion 1.23.0。Cloud Hosts 保持 1.2.2。本文同时记录此前尚未统一提交的 0.53.x、0.54.0 开发内容。

## 文件与资产中心

原共享入口扩展为两种视图：文件树展示目录层次；资产列表直接展示文件、所属 Team、员工、群组或频道及相对路径。支持搜索、分页、键盘导航、复制粘贴、拖放和文件预览/编辑。

根目录为 `AgentsCompany`，下设固定的 `Company`、`Messages` 和 `Plan`。原共享区为 `Company/Shared`，不能通过文件操作改名或删除根。Company 展示 Team 的 Workspace 和员工工作目录；Messages 展示群组、频道、共享原件及同层成员目录；Plan 提供 Exports，不自动创建排期。

目录徽标统计直接子目录中包含文件的数量。目录按需加载，文件列表虚拟渲染，本地索引在独立后台线程运行；远端只传输分页元数据，执行位置保持原样。发布附件和未下载的云端文档也可在资产列表中发现，点击云文档通过既有频道下载接口导入。

共享传输仍复制真实文件内容，保留来源。员工只能修改自己的群组/频道子目录；共享根原件与其他成员文件保持只读，需显式复制到个人工作区后编辑。同名冲突给出错误，不覆盖现有文件。

新增英文目录命名与预览/迁移接口。新生成的中文目录转为 ASCII/Pinyin，去除空格及不兼容符号，保留文件原名。已绑定的外部目录也可纳入用户明确执行的迁移。迁移更新 Team/员工绑定及会话元数据，保留身份、引擎和原生会话引用；兼容映射与默认隐藏的旧路径链接维持原引用。常见工具的 ASCII 技术目录保持兼容，失败有恢复路径。

## Telegram 和频道文档

频道支持 PDF、EPUB 和其他文档元数据；外部采集器可提交文件名、类型、大小、SHA-256 和缩略图。独立的云端采集服务负责持续下载和缓存；Agents Company 通过注册主机把选中的文件下载到频道工作区，提供进度、校验、错误和已保存状态。

新增 English Trunk 频道使用近 48 小时首次导入及后续持续采集。该采集服务属于独立部署项目，不包含在本桌面安装包中；本仓库提供频道协议、存储关联、展示及下载入口。

文档显示保留真实文件名和扩展名、原始缩略图、大小及原消息相册顺序；无原始缩略图时显示文件类型图标。频道还显示来源头像、订阅数、浏览数和反应等已采集信息。下载到频道后，云端缓存或新闻记录删除不会同时删除本机导入文件。

## Company 聊天与定位

Company 中的 Coding Agent 聊天按 ESC 返回主页面，效果与 Back 一致，并保留未发送草稿。文件名输入等内层编辑先处理自己的取消，不会直接丢弃整个聊天。

底部定位入口更新为团队总览面板，包含缩略地图、当前视口、团队列表和定位全部。定位操作改变客户端摄像机，不修改公司共享布局；支持当前 Company 视图筛选、明暗主题、窄窗口及显隐偏好。

## Messages 目录和会话管理

会话目录支持 All Conversations、类型筛选、搜索和用户自定义类别；Group/workers 等入口按实际类别显示，类别可维护，空结果与归档入口保持可恢复导航。

群组和频道具备独立的英文职位 `Owner`、`Admin`、`Member`。这些职位与 Company 的 Secretary/Governor/Manager 权限分别检查。支持实际成员范围内的管理者任免、所有权转移、静音、单人和全员禁言及相应保护；旧群不会因为应用升级自动指定 Owner。

新增固定正文通知：一次、间隔、每日、每周规则，支持预览、历史、暂停/恢复和修订冲突检查。通知由独立服务发布并明确标识；不启动 Agent，不进入 Plan，不伪造模型回复和已读状态。静音保留通知正文，抑制应用内提醒。

群组/频道文件保存在原有共享工作区，用户原件与成员目录同层。分享文件通过现有消息和存储接口完成，文件权限不随可见职位或目录名改变。

## Secretary、Plan 和原生引擎

原生引擎使用统一认证 Core API 工具与命令发现，仍经过原职位、工作区、会话成员和执行权限检查。完整公共文档按索引和单命令 schema 获取；知道接口不代表取得执行权限。

Plan 查询返回真实任务 ID、revision、员工/Team、规则、时间和可执行操作。Secretary 可以查看和维护目标员工已删除的排期记录，但缺失目标不能执行。补充批量删除、保存视图、筛选查询、CLI 参数透传和 GUI/API 对照。

保持每条消息的 source-view、精确引用、转发上下文、阅读回执及初始化身份边界。未传来源时保持未知，不从其他客户端当前界面推断。消息历史检索使用派生索引和独立 Worker，保留原消息、正文、引用及分页语义。

## Margin Reader 0.9.4

### 文档和脑图的阅读工作区

当前阅读产品聚焦文档与同一学习集的原生脑图。两者可单独打开或左右并排，支持交换顺序和调整分栏比例。阅读页码、脑图缩放/中心及分栏设置可恢复，外部 CLI 修改能同步；脑图平移和缩放不滚动文档。

保留摘录与真实原文位置的关联，点击主题可回到 PDF 等来源。文档资料使用完整、按比例的 PDF 封面和 HTML 预览，紧凑展示标题、格式、大小、页数与目录层次；预览使用已有懒加载和缓存，不裁成顶部横条。

### 拖放和结构

把主题 A 拖入主题 B 的主体，B 成为 A 的父主题，整个子树一起移动。主体上、中、下区域采用相同父子语义；同级排序使用主题外插入区域。绿色目标反馈、整支预览和一次撤销保持一致，总览合批主题也可操作。

拖出脑图区、进入相邻文档/浮层后松开，或按 Escape、失焦、取消指针时取消，不改写模型。Alt 保留显式自由摆放；拒绝拖到自身和后代。修复旧矩形挡住重叠目标，以及拖出画布仍改变结构的问题。

### 保存、设计与导出

Ctrl/Cmd+S 明确保存脑图及详情草稿；保存后能正确关闭插件窗口。版本冲突保留草稿，不自动覆盖其他窗口。删除、批量删除、撤销及回收恢复走公开 Core 接口。

保留 54 种自主设计骨架、混合拓扑、独立中心和层级样式、自定义配色、本地设计库、关系线、外框、概要、搜索/标签、键盘编辑、对齐分布、折叠展开与同步过渡。减少动态设置和大图降级保留编辑与完整模型。

支持本地公式矢量渲染、演示模式以及 SVG/PNG、矢量 PDF、PPTX 等既有导出；新增大纲、任务时间视图和区域操作。导出使用完整模型，不因分页或视口挂载丢失节点。能力边界及商业格式差距见插件内专项文档；不声称完整复刻 XMind 或 MarginNote。

## MiniNotion 1.23.0

日历、小时网格、时间线和概览使用同一事件摘要。短事件保留可点击高度但不延长实际时间；拥挤日期、全天事件和重叠事件提供可访问的溢出/滚动。重复模板、生成实例、预览、暂停规则及稍后提醒分别标识，提醒使用有效时间和时区。

编辑器颜色菜单以真实色块预览文字和背景色。斜杠菜单提供横向分类、拖动排序和分类管理；搜索跨分类，删除分类不删除命令。

选区机器人可直接把选中文字发送到已有、授权的宿主员工，在小聊天框展示对应回合的流式文字。可设置提示词、目标员工及先编辑再发送；没有绑定时先选择员工，忙碌或权限失败显示真实错误，不悄悄切换员工。点击框外或 ESC 关闭聊天框，不取消已发送工作。这些宿主接口仍按当前身份授权，不创建独立 Agent，也不确认用户已读。

应用包统一携带 Margin Reader 0.9.4、MiniNotion 1.23.0、Cloud Hosts 1.2.2。安装后还需验证实际加载的外部插件覆盖目录，不能仅根据 bundle 内版本宣称更新完成。用户工作区和文档位于程序外，安装不将其搬入应用二进制。

构建与验证使用隔离状态、确定性协议、headless 浏览器和隐藏 macOS 窗口；没有为了发布验证发起收费模型任务。测试、实际安装版本和提交指纹记录于本次本地发布验收报告。已通过、已修复失败、跳过和未测试平台分别列出。

本次本机目标为 macOS Apple Silicon；Windows 原生桌面及 Linux Agents Company 原生部署需要其各自环境验证，不能根据本机成功推断。素材再分发审核保持原状态；此次推送源码，不自动上传安装包或创建公开二进制 Release。
